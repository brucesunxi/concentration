家庭网页首次打开也按浏览器语言优先顺序选择已支持的英语或简体中文；繁体中文不被误当成简体中文，手动选择继续保存在本浏览器。隔离浏览器已验证中文、繁体中文回退及刷新后偏好保持，见[网页语言入口验收](qa/web-language-entry-v0.46-qa.md)。

## 本批交付

原先 v0.1 静态原型已保留，通过 `npm run dev:legacy` 启动。当前 **v0.46 本地家庭应用** 在首批闭环上继续建设：

1. `apps/family-web`：React / TypeScript 家庭空间，中文与英语文本、儿童插画与青少年图形主题、四类练习、家长记录、生活观察、资料与数据入口。
2. `packages/task-engine`：基于种子的确定性计划，实际输入事件回放、服务端计分、练习与正式步骤隔离、帮助/中断区分、保守难度规则。
3. `apps/api`：本地家庭身份、儿童作用域、最近家长验证、事件接收和重算、导出/删除/停止采集。非本机来源与缺少 CSRF 验证的写请求被拒绝。
4. PostgreSQL 结构与版本迁移：本机默认 PGlite 持久化，也提供 `pg` 连接器。第二次迁移独立保存课程进度，按已有完成记录回填；自由选择不会跳过推荐课程。
5. IndexedDB 先保存事件再上传，序号/标识去重、冲突拒绝、缺失检测；刷新后中断题重做。停止采集/删除会清理当前浏览器的相关缓存；其他标签页收到权限变化后清除旧家长画面。
6. 固定 MP3 播放器使用与内容指令逐字匹配的素材，不调用实时模型。四年龄段、两语言、四任务共 32 个组合均已接入候选语音；母语听审和设备播放验收尚未完成。
7. 引擎 2.0.0 保留固定响应窗口、重复输入和技术排除；设备/输入/内容形成独立比较条件。旧 1.0.0 记录保持原解释；近期帮助/中断不会被升级算法跳过。
8. 32 个签名开发内容包绑定任务/年龄/语言/资产，客户端验证后解码加载；服务端不可变登记与召回、双角色独立审核签名验证已实现。全部实际素材仍未专业审稿；v0.13 已接通本地工作台，真实审核、完整资产制作与生产信任体系待建设。
