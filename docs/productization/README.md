# 专注力家庭产品：产品化方案与技术设计

版本：设计基线 1.0 · 2026-10-01 · 状态：v0.40 本地实施，已增加默认关闭的市场准入矩阵、正式监护核验边界、两端采集状态和孩子自主开始邀请，并建立 Android 版本码递增的本地测试包及原生家庭入口的读屏基础；真实核验服务及家长同意界面未接入，iOS 模拟器包缺 Keychain 权限，原生练习、设备验收与完整发布要求仍未完成。

## 结论

当前工程交接见 [实施进度](IMPLEMENTATION.md)、[下一阶段交接](NEXT-DELIVERY.md)与[市场准入契约](RELEASE-SCOPE.md)；完整语音制作范围见 [语音缺口清单](qa/content-readiness-v0.28.md)。原生声音与安全存储的设备限制见 [v0.29 验收](qa/audio-fallback-v0.29-qa.md)。面向产品和团队的原方案继续作为目标基线。

已补交包含声音降级和安全存储重试的 [v0.29 本地测试包](qa/audio-fallback-v0.29-qa.md#本地测试包)。iOS 模拟器包已安装并显示重试页面，系统诊断指出其 Keychain 权限缺失；Android APK 已签名核验但未安装。实际加密、登录、声音和设备流程仍未验收。

以当前三个小游戏为实验起点，建立面向全球家庭的「注意相关技能练习 + 生活中的策略实践 + 家长支持」产品。目标年龄暂定 **6–17 岁**，按 6–8、9–11、12–14、15–17 岁分别设计；用户是家庭家长和孩子，不以学校、机构管理系统为主线。

产品真正需要加深的是：任务协议是否可靠、孩子是否理解、能否把策略带进生活、家长能否提供合适的支持，以及是否有证据说明产品带来了变化。增加关卡、延长使用时间、生成更多报告，都不能单独回答这些问题。

## 本次设计的七项决定

1. **全球架构，分市场发布。** 英语、简体中文先做内容验证；国家、年龄、语言、任务版本分别设开放条件，翻译完成不等于可以上市。
2. **儿童与青少年两套体验。** 共享任务引擎与家庭账号，但故事、美术、语言、目标和家长共享方式不同。6 岁以下作为独立研究方向，不向下直接套用。
3. **训练与生活实践相连接。** 每次练习只教一个可执行策略，结束后安排一个短小的现实任务；不把游戏分数包装为「专注力指数」。
4. **语音仍使用预生成素材。** 延续已认可的 Azure 中文音色，制作与校对固定语音包；运行时播放文件，不接实时大模型，不上传儿童语音。
5. **完整团队并行建设。** 建议约 12 个全职等效岗位，以 32 周为有限市场发布目标；效果研究另有完整观察周期，不能以版本上线代替。
6. **先建立可信的基础能力。** 首批四类任务、家庭账号、监护人同意、可靠记录、跨设备恢复、家长周报、内容发布系统与支付闭环优先。
7. **效果按证据逐步表述。** 上市初期提供适龄练习和家庭支持，不宣称治疗 ADHD、提高智商或保证学习成绩。任何效果主张须限定到经过研究的版本、人群和结果。

用户已确认面向全球家庭，且已有完整研发团队。下述约 12 个全职等效岗位是能力和工时分配参考；执行时把负责人映射到现有团队，不以重新组建团队为前提。6–17 岁是当前建议的首期覆盖范围，各年龄和市场仍分别验收。

## 设计起点与当前实现

设计起点是三个任务、单设备数据和 16 段固定 MP3 的静态原型，原有 20 项检查构成迁移基线。已新增家庭客户端、四类任务、双语文本、权限与持久化服务；v0.4 接入原生入口与加密日志，v0.5 补齐原生资料管理和计时修复，v0.6 增加规则化周回顾，v0.7 更新图片并保留历史素材，v0.8 接通家庭生活目标，v0.9 增加签名续练授权，v0.10 接通换设备确认和旧记录恢复，v0.11 增加原生断网恢复入口，v0.12 增加 Web 断网重开与跨页保护，v0.13 接通独立内容工作台和双审发布/召回，v0.14 接通候选任务试玩、回执核对及审核关联，v0.15 接通 PNG/MP3 导入、来源声明与换稿，v0.16 接通生活回顾自主分享和撤回，v0.17 接通家庭网页版本发布与旧资源保留，v0.18 接通两端家长陪伴小课与生活建议联动；v0.19 接通真实 PostgreSQL 家庭隔离与运行权限分离；v0.20 接通两端账号管理和执行身份复核；v0.21 接通两端练习与休息、家长上限与暂停安排；v0.22 接通单次总期限和安全间隙询问；v0.23 接通独立家长账号、邀请确认、孩子范围与成员撤销。v0.24 接通家长课与生活目标的三项审阅、签名发布及召回。v0.24 的 264 项自动检查、12 项真实接口检查及 15 项 PostgreSQL 检查通过；内置浏览器已完成中文儿童与英文青少年恢复流程，原生 App 界面、实际加密文件和设备复验尚未完成。详见 [实现进度](IMPLEMENTATION.md) 和 [前批内容验收](qa/family-content-v0.24.md)。v0.25 完成家庭 Web 小屏导航、完整菜单与键盘焦点管理；本批构建和浏览器交互检查通过，未重跑完整业务套件，详见 [小屏验收](qa/compact-family-v0.25.md)。v0.26 接通两端练习与观察的历史翻页，271 项业务、13 项接口及 16 项 PostgreSQL 回归通过；最终专项、构建、原生导出和 Web 故障重试证据见 [当前验收](qa/history-v0.26.md)。

## 立项后必须明确的五个业务决定

这些事项不阻止当前设计，但各有明确截止点：

- 第 2 周：目标经营主体、首发国家名单与销售渠道。
- 第 4 周：首个效果研究的人群、主要结果指标及研究伙伴。
- 第 4 周：12 个全职等效岗位是否到位，供应商预算上限。
- 第 8 周：是否接受儿童版与青少年版两种原生应用发布形态。
- 第 16 周：根据家庭试用与付费访谈确定首发价格，不提前以价格假设承诺收入。

评审采用「证据、负责人、通过条件」记录。未通过某个国家或年龄段的门槛，只关闭该范围，不默认扩大到全世界。
