# 孩子自主开始练习：v0.38 交互契约

面向 6–17 岁家庭使用。开始邀请是尊重孩子参与意愿的产品交互，不是身份验证、可验证监护同意或研究知情同意。

## 进入与退出

1. 家长或孩子在首页选择推荐练习或任意任务后，先显示属于该孩子年龄档与练习语言的邀请。6–11 岁用简单、具体的语句；12–17 岁明确说明由本人决定，不使用幼儿化故事口吻。家长作用域额外看到“把屏幕交给孩子”的提示。
2. “稍后再说/暂不参加”、关闭按钮和 Esc 都关闭邀请；此时不调用新建练习接口，不创建会话，也不把拒绝写成一次练习结果。没有惩罚或倒计时。
3. 只有点击“我想开始/我愿意开始”后才调用新建练习接口。客户端重新检查当前孩子、登录代次和服务端返回的采集状态；服务端继续独立复核市场、监护许可、任务预算和内容状态。成功后进入原有规则示范，示范与正式步骤仍分开。
4. 开始之后仍能休息、提前结束或在设备允许的情况下恢复已经创建的练习。已经创建的历史会话不重新进入这张邀请；家长撤回采集仍按服务端规则立即阻止新数据。

## 不能由此推断的事

这张邀请不能证明屏幕前是谁，也不能代替法域要求的监护核验。用户点击“开始”不应被保存或宣传为法律同意或研究参与意愿的有效证明。进入真实家庭研究前，研究团队仍须审定适龄招募、解释、退出和不适处理材料，验证孩子确实理解并能自主拒绝。

实现与本地验收见 [v0.38 记录](qa/child-invitation-v0.38-qa.md)。

## v0.46：开始前安排更新

邀请页保持读取今天的安排：最长每 5 分钟、临近服务端家庭午夜，以及网页重新可见/获得焦点或原生回到前台时重新确认。日期、设置或额度变化后显示更新提示；暂停、额度不足、采集停止或无法确认时关闭开始按钮，仍可选择不参加。读取与刷新都不自动开始。分龄变化时要求返回家庭空间重新选择，不沿用旧年龄的邀请文字。

当前两端在点击开始时提交 `practiceReview`，绑定看到的家庭日、设置版本、分龄/语言、当前分钟与确认/预留/可用额度。服务端在创建事务内比较这些值：不同返回 `409 PRACTICE_PLAN_CHANGED`，不创建会话、不切换儿童凭据，用户需要重新选择并看说明。在批准矩阵模式下，新会话缺少此信息返回 `428 PRACTICE_REVIEW_REQUIRED`；只在开发预览保留旧客户端的无此字段请求。已有会话的完全相同重试和匹配的活动会话恢复仍按原签名处理，不将旧练习换成今天的新授权。

这是防止旧说明被用于创建新练习的工程约束。字段由客户端提交，不证明自然人身份，也不表示合法同意或已验证的孩子意愿。正式监护、内容、地区和研究门槛继续独立执行。验证范围见 [v0.46 开始确认验收](qa/practice-start-review-v0.46-qa.md)。
