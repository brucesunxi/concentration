# 孩子自主开始练习：v0.38 交互契约

面向 6–17 岁家庭使用。开始邀请是尊重孩子参与意愿的产品交互，不是身份验证、可验证监护同意或研究知情同意。

## 进入与退出

1. 家长或孩子在首页选择推荐练习或任意任务后，先显示属于该孩子年龄档与练习语言的邀请。6–11 岁用简单、具体的语句；12–17 岁明确说明由本人决定，不使用幼儿化故事口吻。家长作用域额外看到“把屏幕交给孩子”的提示。
2. “稍后再说/暂不参加”、关闭按钮和 Esc 都关闭邀请；此时不调用新建练习接口，不创建会话，也不把拒绝写成一次练习结果。没有惩罚或倒计时。
3. 只有点击“我想开始/我愿意开始”后才调用新建练习接口。客户端重新检查当前孩子、登录代次和服务端返回的采集状态；服务端继续独立复核市场、监护许可、任务预算和内容状态。成功后进入原有规则示范，示范与正式步骤仍分开。
4. 开始之后仍能休息、提前结束或在设备允许的情况下恢复已经创建的练习。已经创建的历史会话不重新进入这张邀请；家长撤回采集仍按服务端规则立即阻止新数据。

## 不能由此推断的事

这张邀请不能证明屏幕前是谁，也不能代替法域要求的监护核验。用户点击“开始”不应被保存或宣传为法律同意或研究参与意愿的有效证明。进入真实家庭研究前，研究团队仍须审定适龄招募、解释、退出和不适处理材料，验证孩子确实理解并能自主拒绝。
