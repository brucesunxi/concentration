# 家长周回顾：规则、数据与交接

> v0.22：当前规则为 `weekly-descriptive-2`。新增单次期限/休息询问条件分组，旧记录与新规则记录分开；未知或不匹配的规则抑制差值。历史基础算法见下文，新增实现见 [练习期限设计](PRACTICE-WINDOW.md)。

平台 0.6.0，规则 `weekly-descriptive-1`，2026-09-30。对应产品方案的三张家长卡：练过什么策略、相同条件里的任务记录、生活中的具体尝试。Web「成长记录」与原生「家长空间 → 练习与生活记录」已接入；界面与设备验收仍待完成。

## 家长看到什么

默认显示家庭时区里的本周，支持前后切换最近 52 周。页面列出每日已确认练习和观察、完整与提前结束次数、数据缺口，以及以下三部分：

1. **练过什么策略**：本周尝试次数、独立有效步骤和使用帮助的步骤。不给孩子生成综合能力分数。
2. **相同条件的记录**：两周的分母、正确步骤、目标命中/非目标等待、帮助、中断与排除分别显示；可展开比较条件。只在条件允许时提供描述性百分点差值。
3. **生活观察**：按活动和关联任务分组，显示记录数、孩子自选次数及提醒次数范围。活动难度与时长没有统一，提醒次数不会被换算成能力增长。

没有练习记录的日期明确标为数据缺口，未来日期单独标记。这不是出勤率、约定完成率或儿童排名，未观察到记录不能推断孩子没有尝试。文案允许孩子不谈当天经历，也不要求加练来凑比较样本。

## 时间归属

- 一周为家庭当地周一到周日，按已配置 IANA 时区计算。客户端语言和设备时区不会移动周边界。
- 练习按**服务端确认日期**归周；离线补传可能出现在较晚一周。当前没有可靠的跨设备离线墙钟证据，不能伪装成已还原实际完成日期。
- 观察按服务端保存日期归周，尚无单独的活动发生日期字段。
- 当前周一直标记「进行中」，不与完整的前一周计算差值。已结束周才可能比较。
- 服务查询先使用宽一些的 UTC 日期范围，再按家庭当地日期精确筛选。日期计算采用日历运算，没有把跨夏令时的一周假定为固定 168 小时。

## 分组与差值规则

分组键显式包含：任务、引擎和策略版本、等级、年龄段、语言、平台、设备类别、输入方式、模态，以及内容 id、版本和摘要。即使历史 `condition` 字符串被复用，结构化条件不同也不会混合。

统计从服务端已确认结果中的试次重新汇总：示范不进入正式分母，帮助步骤单列；计算整体分子/分母，不平均每次练习的百分比。搜索/记忆显示独立步骤正确率；Go/No-Go 与持续留意使用目标命中率和非目标正确等待率的平均值，避免「一直不点」得到高评价。

以下情况只展示记录，不计算差值：

- 当前周未结束。
- 元数据不足或不是当前可比较协议。
- 两周内存在未确认会话或条件不一致的记录。
- 任一周同条件记录包含帮助、中断、排除或提前结束；不跳过这些尝试来挑选较好的样本。
- 任一周样本不足。

当前样本门槛延续开发方案中的保守起点：每周至少两次同条件记录；搜索至少 12 个独立步骤和 24 个目标机会，记忆至少 20 个独立序列，抑制至少 40 个目标/20 个非目标，持续留意至少 20 个目标/40 个非目标。**这些是待专业审核的展示规则，不是已经验证的统计功效、临床阈值或疗效证据。**

允许显示的差值只是描述这两周任务结果的百分点变化，不能据此声称生活迁移、注意力能力改变或产品因果效果。规则版本随响应返回；历史原始记录保持不变。

## 接口、快照和权限

`GET /api/children/:id/weekly?weekStart=YYYY-MM-DD`。省略 `weekStart` 时使用本周；传入值必须是最近 52 周内的周一。不存在的日期、未来周、重复参数和未知参数均拒绝。

- 仅已验证家长可访问；检查家庭归属，儿童凭据和其他家庭无法读取。
- 查询在事务中锁定档案，与现有采集、观察、撤回、结束处理保持一致的记录快照。结果不继承旧记录列表的 50 条显示上限。
- 本地同步查询最多扫描 5000 条会话和 5000 条观察，超过时返回明确错误，不生成截断后仍看似完整的趋势。此上限也包含为时区边界而查询的外围日期；大规模异步周报仍待建设。
- 响应带 `no-store`，没有独立保存周报副本。删除档案后接口返回未找到；停止采集后家长仍可回顾保留的历史记录。
- 响应不包含密码、认证令牌、CSRF、设备标识、会话种子或原始事件。
- 数据库迁移 6 增加会话报告时间及观察时间索引，不重写旧结果。

| 文件 | 职责 |

| `packages/reports/weekly.ts` | 家庭日历、分组、计数、比较门槛和确定性响应 |

组件按档案挂载；过期请求不能覆盖新档案，响应的 childId 也必须匹配。原生家长空间进入后台时关闭，晚到响应不恢复报告。上述设备行为仍需要实际操作验证。
