# 家长陪伴课程与生活建议

平台 0.18.0，更新于 2026-10-01。这次把家庭方案中的家长支持部分接入 Web 与原生代码：家长可按孩子的课程阶段阅读短章节，再把建议带到生活目标中商量。阅读不生成儿童表现记录，也不会直接保存目标。

当前在线契约为 `parent-guide-2-preview`；内置种子内容仍待真实专业审核。四年龄段、中文与英文已经有可运行的内容视图；适龄性、母语质量和日常效果尚未验证。本批是开发交付，不是全球商业发布或方法有效性结论。

本地 v0.24 已接入按年龄选择的签名发布包，契约升级为 `parent-guide-2-preview`。两端区分未审核与本地审核预览；召回/到期时清除正文。实际签名、工作台和验收见 [家庭内容发布](FAMILY-CONTENT.md)。

## 家庭使用流程

家长登录 → 选择孩子 → 家长陪伴小课 → 阅读当前建议或其他主题 → 打开生活建议 → 调整目标及帮助方式 → 明确保存家长建议 → 交给孩子选择是否接受。

每节包括：目的、一句邀请示例、当前年龄段的生活例子、三个步骤、困难时的退一步做法、家长可留意的事实。先问意愿、允许求助、休息和拒绝贯穿章节。青少年例子围绕个人项目与自主安排，不要求提交私人想法。

| 章节 | 陪伴主题 | 对应推荐任务 | 可打开的生活模板 |
|---|---|---|---|
| 准备 | 先听孩子的想法，认识帮助和退出 | 无 | 无自动推荐 |
| 1 | 确认目标，分小片查看 | 搜索 | 找物 |
| 2 | 商量轮流与暂停 | 抑制 | 轮流 |
| 3 | 拆开事情，保留步骤卡 | 记忆 | 步骤 |
| 4 | 分心后找到返回的一步 | 监测 | 返回 |
| 5 | 换材料，再试熟悉策略 | 搜索 | 找物 |
| 6 | 让孩子选择提醒方式 | 抑制 | 轮流 |
| 7 | 自己核对，允许求助 | 记忆 | 步骤 |
| 8 | 回顾、保留或结束 | 监测 | 返回 |

共 9 节，每节有 6–8、9–11、12–14、15–17 岁四种生活例子，所有字段提供简体中文和英语。共享的是陪伴结构，36 个年龄例子分别编写；这不意味着已有 36 份专业批准。

## 与现有课程的关系

沿用 `courseUnit(course_units)`，每三个完整推荐任务对应一个阶段，共 24 个课程单位。家长课的当前建议来自服务端同一计数，覆盖 0–24 的全部边界；不根据设备日期、阅读次数、家长观察或自由选择练习的总完成数推荐阶段。

准备章节随时可看。完成基础课程后仍可阅读第八节和其他主题，也可以停止使用。章节不锁定，不设置阅读打卡、倒计时、排名、补课或自动续课。

现有首页仍沿用“课程周”的历史文案，这里的“阶段”解释其按个人进度推进的含义。本批不改变引擎、任务顺序、计分或推荐课程升级规则。后续若专业团队改变课程节奏，须同时变更引擎、指导和验收协议，不能只改标题。

## 接口与数据边界

`GET /api/children/:childId/parent-guide`

- 仅当前家庭的家长作用域可访问；孩子凭据返回 `PARENT_REQUIRED`，其他家庭或已删除档案返回 `NOT_FOUND`。作用域不证明屏幕前人的真实身份。
- Web 使用现有 Cookie；原生使用现有本机 Bearer，继续禁止跨传输混用。
- 响应包含 `childId`、`ageBand`、`version`、`review`、`collectionActive`、`course`、`recommended`、`lessons`；`Cache-Control: no-store`。
- 本接口只读，没有阅读历史、答案、阅读时长或完成标记，不新增数据库表。导出结构、删除链路与儿童课程记录没有新增实体。
- 停止采集后，所属家长仍能阅读。客户端禁用生活建议入口；生活目标接口继续独立校验采集状态，不能靠旧页面绕过。
- 不新增第三方调用、实时模型、语音采集、通知、支付或账户权限。

`version` 和 `review` 在客户端校验；不同档案或不兼容的内容契约不能显示为当前内容。当前客户端接收可用的 `unreviewed` 或 `approved` 本地预览，检查所属档案、契约和内容可用状态；签名与实际独立审阅由服务端验证。

## 两端实现

| 层次 | 文件 | 职责 |
|---|---|---|
| 内容 | `packages/family-support/parent-guide.ts` | 原创双语稿、分龄例子、课程对应和生活模板映射 |
| 契约 | `parent-guide-model.ts` | 版本、章节和响应类型；客户端不包含整份服务端课程稿 |
| 读取 | `parent-guide-client.ts`、`useParentGuide.ts` | 只读加载、15 秒刷新、错误清除旧快照、销毁后忽略晚到响应 |
| 界面文案 | `parent-guide-copy.ts` | 双语说明、错误和阶段展示 |
| API | `apps/api/service.ts`、`main.ts` | 家庭/家长权限、档案读取、只读响应 |
| Web | `apps/family-web/src/ParentGuide.tsx` | 懒加载页面、章节导航、焦点移动、窄屏折叠目录 |
| 原生 | `apps/family-mobile/src/ParentGuide.tsx` | 共享内容与读取逻辑、可收起的主题选择 |
| 生活目标 | 两端 `LifeGoals.tsx` | 接收模板预选；保存仍需明确点击，已有开放目标优先展示 |

两端使用家庭和孩子标识作为组件键。切换档案/角色后销毁旧读取器；刷新失败清除可操作快照，不把上次成功内容当作最新授权。15 秒刷新只是在线同步措施，不是跨设备立即撤销保证。

章节选择与预选仅留在当前页面内存中，不形成恢复队列。离线时显示无法读取，联网后重试；本批不提供陪伴内容离线阅读。生活目标原有幂等、冲突、孩子选择与回顾分享规则继续生效。

## 方法来源与审核工作

Harvard Center on the Developing Child 的活动指南提供了从婴幼儿到青少年、由成人支持执行功能练习的分龄活动背景。[原始指南介绍](https://developingchild.harvard.edu/resources/handouts-tools/activities-guide-enhancing-and-practicing-executive-function-skills/)（发表于 2014-05-06，核对于 2026-10-01）。它不验证本产品、不规定本产品的四个年龄段，也不证明本套软件能改善日常注意力。

本次章节和邀请话术是依据既有[产品方案](PRODUCT-PLAN.md)及[家庭生活目标设计](FAMILY-LIFE.md)编写的产品稿，没有复制原指南章节，也没有使用专业人士名义批准。内容需完成以下工作后，才可纳入面向家庭的正式发布范围：

1. 方法负责人逐项检查目的、语言、活动负担、退出方式和家长误用风险。
2. 每个年龄/语言组合完成专业与母语复核，包括残障与不同家庭安排下的可用性。
3. 使用 v0.24 已接通的冻结、方法/中文/英文三项独立审阅、版本追溯与召回流程，完成真实专业审批。基础稿仍未获得这些批准，见 [家庭内容发布](FAMILY-CONTENT.md)。
4. 在获准的研究/试用流程中观察理解、亲子互动、负担和退出原因。若要宣传生活改善，仍需产品自身的研究证据。
