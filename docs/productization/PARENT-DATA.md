# 原生家长资料管理与可靠清理

版本：平台 0.5.0 / 移动端 0.2.0，2026-09-30。本文描述实际代码；全球身份、可验证监护同意和生产删除链路仍按总方案建设。

## 家长可以做什么

原生家庭卡片进入「记录、观察与资料管理」，提供三个页面：

1. **练习与生活记录**：本次独立步骤、帮助、中断、完整/提前结束，以及生活观察。最多显示最近 50 条练习与 50 条观察，观察总数独立统计；不生成能力评级。
2. **记一次观察**：选择关联练习和具体生活活动，记录 0–20 次提醒，以及是否由孩子选择。界面明确一次观察不能证明能力变化。
3. **资料与权限**：导出、停止采集、删除。先说明具体范围，要求家长再次输入密码；删除还须完整输入昵称。停止采集保留服务端历史记录供导出，拒绝新练习、新观察和旧会话补传。

服务端仍独立验证家长权限和最近十分钟内的身份验证。儿童凭据不能执行这些操作，隐藏按钮不作为权限保证。离开 App 会关闭家长页面；请求在后台晚到时不能恢复旧画面或再发起尚未执行的敏感操作。

## 生活观察的重试

第五次数据库迁移为 observations 增加请求标识、规范化内容摘要和按孩子唯一的索引，原有观察保持可读。Web 和原生都为同一份未确认内容保留请求标识：

- 相同内容重传返回原记录 id，不再增加一条观察。
- 相同标识携带不同内容返回 `IDEMPOTENCY_CONFLICT`。
- 更改输入作为另一份内容处理；已经确认保存后，新一轮观察获得新标识。
- 同意/权限检查先于去重；停止采集后不能以「只是重试」继续写入。
- 请求标识和内部摘要不出现在家长导出中。

运行接口 `POST /children/:id/observations` 现在要求 `Idempotency-Key`。这适用于本地开发契约，不是已经完成正式 `/v1` 兼容治理的声明。

## 三种结果必须分开

| 实际状态 | 界面处理 |
|---|---|
| 请求失败，无法确认服务端是否处理 | 显示失败并允许重试，不先删除本机未确认记录 |
| 服务端已确认，本机清理失败 | 明确显示本机清理待完成，提供重试 |
| 服务端与本机都完成 | 告知处理范围；不声称第三方或已导出副本也被删除 |

删除请求的回复丢失、无法读取、返回服务端错误或重试收到 `NOT_FOUND` 时，重新取得同一家庭有效创建者的完整档案列表。只有确认该档案已不存在，才能完成本机清理；协作家长、待批准家长或另一家庭的空列表不能作为证据。停止采集的回复丢失时，需要在列表中看到该档案明确标记为 `collection-withdrawn`。网页与原生端共用此核对规则；网页仍允许家长在本机清理失败后再次点击重试，不把服务端已处理误报为全部完成。

## 本机日志如何防止重新出现

SQLCipher 日志增加 `blocked_profiles`。确认停止采集或删除后，在一个事务里记录阻止标记并删除日志。保存语句同时检查该标记，旧页面或排队中的写入无法用新会话 id 重新生成被清理的记录。

所有数据库操作通过一个串行队列，在同一条已经设置密钥的连接上执行。不能直接使用 Expo 的 `withExclusiveTransactionAsync`：当前版本会创建新连接，而连接不会自动继承原先的 `PRAGMA key`。清理采用同连接事务，其他读写不会混进事务。

家长重新登录或刷新时，以服务端档案列表核对本机日志：完整列表只提供给有效的家庭创建者，可据此清理已删除档案；协作家长和待批准成员只会看见部分或空列表，不能据此推断其他档案已删除。两类家长都可以清理列表中明确标记为 `collection-withdrawn`（停止采集）的档案；临时缺少监护核验或开发预览确认不等于永久撤回，不能据此永久阻止本机写入。Web 浏览器与原生 App 均按此边界处理，清理后阻止旧页面重新写入。旧版浏览器日志如果没有家庭标识且档案已从列表消失，无法可靠归属到哪个家庭，只能等待七天本机保留期届满或由家长主动清除本机缓存。

阻止标记只保留家庭/档案随机标识，不保留昵称、事件或观察；仍存放在加密库中，用来拒绝晚到写入。这属于技术性残留，正式产品的保留期限与清除策略仍待审阅。数据库逻辑清理不等于完成存储介质、系统备份和所有设备的物理擦除。

## 导出范围与平台差异

导出包含服务端的完整档案、会话、事件、观察和开发确认记录，另附 `localRecovery`：**此设备**当前保存的恢复日志及采集快照时间。恢复日志可能包含服务端已接收但设备尚未确认的事件，不能直接相加计算成绩；其他离线设备不包含在内。

序列化前检查档案 id、格式与记录数组，并拒绝嵌套的密码摘要、会话凭据、CSRF、请求标识和内部设备标识。移动导出暂限制为一千万个 JSON 字符，超出时提示使用 Web；这不是生产异步导出方案。

### iOS

家长选择导出后，将文件写入 App 私有临时目录，再打开系统分享窗口。文件名不带孩子昵称；窗口完成后清理临时文件，启动/回到前台时也清理遗留文件。仍在分享的文件不会被清扫。

分享接口的返回不证明文件已经保存到某处，因此提示家长自行核对目标位置。[Expo Sharing 文档](https://docs.expo.dev/versions/v57.0.0/sdk/sharing/)

### Android

使用系统目录选择器，获得家长对所选目录的授权后创建 JSON 文件并写入，成功写完才标为保存成功；取消选择不创建文件。写入失败会尝试删除这次创建的不完整文件，若清理也失败则明确提示。

这里不依赖「分享选择器已经关闭」推断目标 App 已读完文件，避免提前删除 FileProvider 文件造成导出失败。只访问家长主动选择的目录，开发配置移除旧式整机外部存储读写权限。[Expo FileSystem 文档](https://docs.expo.dev/versions/latest/sdk/filesystem/)

已保存或分享出去的副本由家长管理，停止采集和删除档案不能撤回这些副本。系统保存/分享流程由家长主动启动；App 不自动向任何人发送资料。

## 验证与未完成项

本批 81 项自动检查已通过，新增覆盖：观察并发重试、内容冲突、撤回优先；不同家庭与后台中断；删除回执丢失；本机清理失败；导出串入凭据；SQLite 阻止标记、队列顺序和失败恢复。三个真实 HTTP 检查通过，新增原生家长观察—导出—撤回—删除全流程与重启后的删除状态。

这些检查不代替系统保存/分享、实际 SQLCipher 文件、后台/锁屏及无障碍操作的设备验收。当前二进制和界面证据见 [v0.5 验收记录](qa/parent-data-v0.5.md)。完整离线租约、多设备即时撤回、生产备份与供应商删除、正式同意及合规证明仍未完成。

## v0.16 生活回顾答案的可见范围

生活目标及回顾结束状态保留。未分享的答案不接收或存储；明确分享及历史已共享答案可出现在家长记录和导出中。孩子或最近验证的家长可以撤回已有答案，事务清除目标、历史载荷及答案派生摘要；此后导出只含撤回标记。以前查看或下载的副本不能收回。停止采集不自动删除既有历史，但最近验证的家长仍可移除共享答案。具体实现与生产副本清理边界见 [自主分享设计](REFLECTION-SHARING.md)。
