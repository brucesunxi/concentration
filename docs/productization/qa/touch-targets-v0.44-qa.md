# v0.44 常用点击区域与档案生命周期交接

2026-10-01。本批是本地开发版的适龄交互改进，尚无儿童或真机操作验收。

## 已实现

- 网页共享主按钮、首页开始按钮的最小高度为 **56 CSS 像素**；次要按钮、文字按钮、小屏导航、资料切换、分段选项及图标关闭按钮的最小点击高度为 **48 CSS 像素**，小图标按钮另设最小宽度 48 像素。历史折叠记录标题也从 30/44 提高到 48 像素。既有可见焦点和减少动态效果规则保留。
- 原生共享按钮的最小高度从 54 提高到 **56 逻辑像素**。原生选择项至少 48、计分题可点图块至少 72，沿用原有标签与读屏语义。
- [年龄档与成年转换实施契约](../PROFILE-LIFECYCLE.md)列出当前不可直接更改年龄档的原因、旧授权与未同步记录的保护要求及实施验收矩阵。它不是已上线的变更入口。
