# 固定语音候选的工程质量检查

2026-10-02。检查对象为 16 份源 MP3，覆盖 32 个年龄／语言／任务内容位置。它们仍是**未获人工批准的本地候选**；此检查不能判断自然度、字幕是否真的听起来一致、适龄性或设备听感。

`npm run voice:audit` 现对每份源文件解码后测量综合响度、真峰值及句首句尾静音，并在 CI 中运行。当前工程警戒范围：综合响度 -24 至 -16 LUFS，真峰值不高于 -1 dBTP，句首静音不超过 500 ms，句尾静音不超过 1200 ms。范围用于阻止明显错误换稿，不是儿童听觉舒适度的临床标准，也不会自动修音或改写已签名素材。

| 测量 | 16 份候选范围 | 本轮结果 |
|---|---:|---|
| 综合响度 | -21.39 至 -19.47 LUFS | 全部在工程范围内 |
| 真峰值 | -5.83 至 -2.99 dBTP | 全部低于警戒上限 |
| 句首静音 | 189–228 ms | 全部在工程范围内 |
| 句尾静音 | 561–973 ms | 全部在工程范围内 |

英语候选的句尾留白为 860–973 ms，中文为 561–631 ms。母语审核时应试听这种节奏差异，不能因自动检查通过就判定自然。合成的过轻录音和多余两秒句尾静音均已验证会被拒绝；源文件没有因本次检查而改变。完整逐文件测量可用 `npm run voice:audit -- --out <临时 JSON 路径>` 重建。

后续仍需：方法负责人核对真实任务规则、中文／英语母语人员逐段试听，目标 iOS／Android 与主流浏览器上的音量、暂停、耳机／蓝牙和静音验收，随后按内容版本完成独立批准。

2026-10-06 制作流程补充：新候选会先在临时文件上通过上述响度、真峰值与首尾静音检查，再以不覆盖已有文件的方式放入候选目录。工程异常会拒绝保存最终文件。此门槛不证明发音、语气、语言内容或儿童听感合格；本次没有调用语音服务生成新录音。
