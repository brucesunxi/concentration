# v0.32 本地确认与采集边界验收

日期：2026-10-01。范围：本机家庭服务及两端共享的家长界面；测试家庭和记录均为虚构数据。

## 已实现

- 每次读取孩子档案时核对 `local_confirmations` 中的目的 `local-development-only-not-vpc`、版本 `local-1`、不晚于当前时间的确认时间和未撤回状态。采集状态同时要求档案开关有效。
- 新练习、旧事件补传、观察、生活目标、练习安排修改、孩子入口和协作家长的孩子授权都使用这个状态。读取既有记录、家长导出、停止采集与删除仍可用。
- `/me` 的 `consentActive` 反映实际可采集状态；`localPreviewConfirmation` 和恒为 `false` 的 `verifiedGuardianConsent` 明确区分本机试玩和正式监护核验。家长资料页用中英文解释这个范围。
- 数据库迁移 26 只增加协作家长对已授权孩子确认记录的读取；原写入权限不扩大。生产入口继续拒绝启动。

## 验证

`npm test`：287/287；`npm run test:http`：14/14；`npm run build`、`npm run mobile:check` 通过。专项测试把确认记录删除、改成旧版本、标为撤回或改为未来确认时间，即使档案开关仍为真，界面状态及所有检查过的采集入口仍关闭，家长可导出并删除。既有协作家长范围、撤销和旧库升级回归通过。

## 未完成的发布门槛

本批未接可信监护核验提供商，也没有按国家/年龄/用途签发正式同意凭据。真实 PostgreSQL 独立角色套件已尝试，但测试容器在 `inspect-image` 阶段失败，未进入任何数据库断言；只读权限仍需在独立角色环境复验。iOS/Android 新包与设备验收、真实家庭试用或内容/声音人工批准亦未完成。这些证据到位前只能用于本机开发评审。
