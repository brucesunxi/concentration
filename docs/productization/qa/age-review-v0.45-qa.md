# v0.45 年龄档复核与旧练习保护

2026-10-01。本批是本地开发验收版本，使用虚构家庭资料；不作为真实家庭招募或应用商店发布的批准。

## 交付内容

- 家庭创建者可以在 Web「家庭空间」或 Android/iOS 原生「记录、观察与资料管理 → 年龄档复核」查看当前档、下次复核时间、待生效档和未结束练习。孩子只看到新练习暂停的简明提示。
- 建档后的复核周期暂定 365 天；到期暂停签发新练习。家长最近一次密码验证超过 10 分钟时须重新验证。复核提交要求版本号、幂等键和明确确认；过期页面、并发操作不能覆盖新状态。
- 换档先进入等待状态，旧档年龄与监护授权保持不变，原设备可按旧签名在授权期限内上传。仍有未结束练习时拒绝生效。生效时清除旧孩子登录、撤回旧本地确认、重置分龄进度和日额度；旧会话的计划、事件与记录保留原年龄档，正式模式需按新年龄重新取得监护许可。
- 18+ 请求只进入等待状态，暂停新练习；身份和资料权利转换尚无实现。若旧设备无法补传已过期的练习，当前不能强制标成已同步，需另行完成家庭处置流程。
