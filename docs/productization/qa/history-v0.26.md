## 浏览器实测

隔离服务 `http://127.0.0.1:4267/`；虚构家庭包含中文 6–8 岁与英文 15–17 岁档案，每个档案 57 条呈现验收用练习结果及 57 条观察。练习结果由提前结束样本复制形成，只用于列表验收，不是训练或效果证据。

1. 两集合首页各 50 条，练习前进后为 7 条，观察保持 50 条；观察前进后为 7 条，末页入口禁用并显示说明。
2. 返回观察上一页不改变练习页码；重新读取最新记录重置两集合；切换到另一个孩子重新加载首页。
3. 成功翻页后，Web 焦点进入对应标题；中文 390px 和英文 320/390px 视口检查未发现横向溢出。属于 CSS 视口模拟，不是真机证据。
4. 在隔离服务暂停响应时，等待请求超时，原页仍显示 50 条且页码不变；最终错误提示在当前翻页按钮旁。恢复服务后直接重试，得到第二页 7 条，错误提示消失。
5. 撤销虚构家庭全部登录后，现有账号轮询先检测到失效并回到登录页面；练习、观察和周回顾均不再显示。因此不能把这次浏览器结果单独归因于翻页组件的拒绝分支；该分支另有共享客户端测试。
