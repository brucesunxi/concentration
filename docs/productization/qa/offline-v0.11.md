## 新增检查覆盖

`offline-session.test.ts` 有 8 项：

- iOS/Android 原计划核验成功，恢复资料不含令牌、密码、昵称或重复事件。
- 错误设备、平台、授权签名、修改后的计划和替换内容均被拒绝。
- 日志缺失、截断、摘要错误、非法事件及超过事件上限被拒绝。
- 过期、回拨、持久化时钟故障或已换设备状态不能通过重开恢复新题。
- 不活动、被替换、状态 ID 不匹配的练习不能准备入口。
- 重启时呈现中的题记为一次中断；重复上传不重复保存，完整确认后只清理一次。
- 跨进程保留最高时间和故障；微小偏差不降低已知时间；无效设备时钟不能清除故障。
- 只接受明确的连接错误类型作为离线候选；HTTP 拒绝、解析异常与一般代码错误不触发降级。

`offline-sql.test.ts` 有 5 项：

- 准备资料必须匹配日志所有者和当前完整事件快照。
- 身份代次变化后旧准备无法覆盖新家庭入口，原日志保留。
- 停止档案和关闭会话不能通过晚到写入或重新打开表结构复活。
- 晚到检查点或重复准备不降低最高时间、不清除已有故障。
- 模拟检查点存储失败时，事件与检查点一并回滚。

这些使用内存服务、同一组 SQL 和共享核验代码；不能替代 SQLCipher 真机文件检查、React Native 界面、实际触控/音频或系统异常验收。
