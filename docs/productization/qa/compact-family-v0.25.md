| 场景 | 观察结果 |
|---|---|
| 家庭空间，视口 320 / 390 / 768 / 1024px | 内容宽度分别等于可用宽度 305 / 375 / 753 / 1009px，无横向溢出；差额为桌面浏览器滚动条 |
| 320px 中文首页 | 四个常用入口均为 69.25 × 60px，文字可见；长昵称换行 |
| 英文 390px 完整菜单 | 七个入口均高 56px；菜单内部内容宽度等于可用宽度；孩子模式标出家长入口 |

| 菜单打开时从 390 改到 1024px，再 Escape | 原小屏入口隐藏后，焦点回到当前页面标题 |
| 从菜单打开家庭空间、生活目标或家长课 | 主标题获得焦点 |
| 英文 15–17 岁生活目标 | 选择项目拆解模板后显示步骤并启用保存；未提交目标，无新增生活记录 |

| 英文账号密码表单 | 仅打开空表单；三输入字号 16px、高约 56.8px；取消成功，没有输入或修改密码 |
| 中文孩子空间 → 更多 → 家庭空间 | 完整菜单关闭，出现“回到家长空间”验证弹窗，焦点位于弹窗内；未跳过验证 |

## 3. 本批修正的缺陷

初次检查发现旧版 320px 视口出现 347px 内容宽度，七个纯图标导航挤出屏幕。改为四入口后消除了该场景溢出。

中间构建还出现关闭菜单后焦点落到页面空白，以及 Tab 到达弹窗边界后离开弹窗的问题。最终版本增加焦点恢复和键盘首尾循环，并实际重测上述路径。中间截图和构建日志仅作过程记录，以下带 `final-` 的截图对应最终构建。

## 5. 仍未覆盖

- 这是 Codex 内置浏览器 CSS 视口模拟，不是手机真机验收；未验证触摸、移动软键盘、安全区、读屏、系统字体放大、旋转或其他浏览器。
- 未把导航检查推定为全部任务界面、全部对话框、所有角色组合或全站可访问性通过。
- 协作家长的导航使用原有权限分支，本批没有额外建立协作账号做浏览器验收。
- 原生包仍为 [v0.24](native-package-v0.24.md)；没有以本批 Web 截图代替原生结果。
- 初始资源预算只剩约 4.2KB；后续增加主入口内容前需继续拆分或减小资源，不能上调预算掩盖增长。
