# 原生读屏操作条件：工程验收

2026-10-02。此批针对 iOS VoiceOver 与 Android TalkBack 的操作方式，为未验证的限时视觉任务设置可靠性边界，并使无单题倒计时的“找一找／记一记”记录可与普通触控分开。它不是完整无障碍认证或经过研究验证的等效训练方案。

## 已实现的边界

- 原生端在显示练习邀请以及实际创建会话前查询系统读屏状态。读屏开启时，“请过桥／看见星星”限时视觉题不给孩子创建会话，告知可选择无单题倒计时任务或今天休息；服务端也拒绝伪造的读屏限时请求。网页没有自动可靠的读屏检测，本批不为 Web 开启读屏协议。
- 原生端的“找一找／记一记”使用 `assistive` 输入条件和独立的计划身份。读屏切换时正在进行的步骤按输入变化排除；切回原操作方式才可重试，也可以回家庭空间重新选练习。恢复旧会话时仍须与原计划的输入条件一致。
- 读屏任务保留正式步骤与孩子选择，但暂不推进基础课程或自动调难度。周回顾把读屏正式步骤单列，不并入普通触控的独立步骤，也不计算读屏记录的两周差值。家长不能把这里的描述性任务结果理解为效果证据。

## 工程核验与剩余验收

- 任务协议、服务端创建/结算与周回顾专项用例通过；完整业务回归 346 项、HTTP 回归 18 项、Web 与原生类型检查、Vercel Web 构建以及 iOS/Android Hermes 导出均通过。Hermes 导出证明代码可打包，不证明设备交互。
- 本机 iOS 桌面控制仍报告 Mac 锁定，且当前模拟器包没有可用的 Keychain entitlement。本批未在 VoiceOver/TalkBack 真机上完成焦点顺序、系统读屏切换、离线恢复、语音混播与触摸时序验收。正式试用前需用目标设备验证这些路径，并由方法、无障碍和分龄内容负责人决定读屏任务是否可作为训练及如何解释表现。
- 目前基础课程仍按四种任务安排；读屏用户可自由选择两种无单题倒计时任务，但无法完成包含限时题的基础课程。专门的读屏课程与音频任务设计是后续产品工作，不应把本批的安全边界误称为完整支持。

后续网页入口已加入每次显式选择与独立记录，见[网页读屏操作验收](web-screen-reader-v0.46-qa.md)。本文件的“网页未开放”表述仅对应原生端这批提交时的状态。
