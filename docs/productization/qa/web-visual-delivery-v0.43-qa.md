## 改动与边界

- 两张**装饰图**从保存的原始 PNG 重新导出为 WebP。质量参数逐文件写入图片制作清单，原始图、透明边缘、原生 PNG 和用于计分的角色／物品图集没有改变。画面仍需设计师及目标年龄儿童人工核对。
- 图片检查现在使用当前锁定的编码器重新导出并逐字节比较，避免交付文件与制作清单悄悄分离。独立网页发布继续使用内容寻址的文件名和离线资源清单，旧网页资源不被同名覆盖。
- Android 核验工具在存在归档源码时，以归档内的版本、原生构建号和逐文件摘要为准；先检查归档清单与文件哈希，再核对安装包。v0.41、v0.42 的旧包在当前源码已前进后仍通过复核。无归档时仍要求当前源码与隔离构建目录匹配。
