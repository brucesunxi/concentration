# v0.40 原生家庭入口读屏基础验收

日期：2026-10-01。此批改动面向本地研发测试，并不代表限时视觉任务已通过无障碍或方法学验证。

## 交互改动

- 页面标题变化时，仅在系统读屏已开启的情况下播报新标题；异步检查返回前若页面已离开，不再播报旧标题。标题仍保留原生 `header` 角色。
- 共用按钮、单选项和复选项提供明确的读屏名称及禁用/选中状态；表单标签由输入框播报，不让同一文字作为独立标签和输入框重复出现。复选框的装饰符号不参与播报，文字仍可随系统字体放大。
- 多孩子首页中，每张档案卡的昵称是标题；卡内练习、生活目标、家长内容和资料操作的读屏名称都带孩子昵称，避免两个孩子的同名按钮无法区分。可见按钮文案保持简洁。

## 尚待验证

没有连接的 Android 设备，也没有可用的 Apple 开发签名身份。尚未在 TalkBack、VoiceOver、大字体、软键盘或实际设备上验证导航、焦点、播报顺序和覆盖安装后的资料保留。四类练习仍是**限时视觉任务**；读屏操作延迟可能改变测量条件，不能把当前控件标签改进解释成这些任务适用于读屏、结果可比较或具备训练效果。正式开放前需设计并验证相应的辅助模式和报告边界，完成目标年龄家庭研究。
