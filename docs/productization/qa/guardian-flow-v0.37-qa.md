# v0.37 监护许可流程与采集状态验收

日期：2026-10-01。范围为本地家庭服务、Web 与原生源码，以及注入合成批准清单和合成核验适配器的测试。没有真实供应商或正式市场用户。

## 本批实现与证据

- 外部核验不再持有家庭数据库事务。服务端在供应商调用前验证创建者身份和孩子资格，最多等待 8 秒；返回后在最终事务内重新验证身份、孩子是否撤回、当前准入规则和证明绑定。供应商失败与超时统一返回暂不可用，原始凭证不写入数据库或日志。
- 并发用例让核验保持等待，同时执行家长撤回；撤回在核验返回前完成，迟到的有效证明被 `CONSENT_REVOKED` 拒绝，许可表没有插入记录。合成测试还覆盖有效、过期、重放、范围变化和撤回后的状态。
- 服务端向客户端返回五种 `collectionStatus`，Web/原生共用中文和英文解释。正式模式建档不要求本地试玩勾选；没有核验入口时明确说明无法开始采集。旧服务没有新字段时显示无法确认状态的保守提示。
- `npm run check`、`npm run mobile:check`、`npm test`（296/296）、`npm run test:http`（14/14）及 `npm run build` 均通过。Web 离线入口 1,486,313 字节，低于 1,500,000 字节限制；本地服务健康接口返回 `0.37.0`。内置浏览器检查了家庭入口窄屏排版。

## 尚未通过的发布门槛

- `npm run test:postgres` 在本机 Docker 镜像检查阶段失败，独立 PostgreSQL 行级权限和并发套件没有运行；上述 PGlite 结果不能替代它。
- 真实核验供应商、正式家长告知与同意界面、地区法务审批、真机离线与撤回演练、母语内容审查均未完成。当前 HTTP 没有正式核验入口，生产启动仍显式拒绝。
- 原生仅通过源码类型检查；没有生成 v0.37 安装包。当前 Android APK 仍是 v0.35，iOS 旧模拟器包受 Keychain 权限问题阻断，不能据此声称原生交互已验收。
