## 每个组合的验收步骤

1. 运行 `npm run voice:content -- --missing-rules --dry-run` 核对四条待录规则；制作时会先检查响度、峰值与首尾静音，合格候选才会写入未跟踪的 `dist/content-rule-candidates`，不会覆盖已签名素材或自动附加内容包。
2. 按表中完整规则和语言制作或复核固定 MP3，把文件、字幕及新内容版本绑定；运行时直接播放已审素材。已有策略录音不得冒充规则录音，旧开发包保持原签名。
3. 母语审核人完整听审发音、语气和适龄程度，方法负责人对照任务规则及判分检查指令。审核依据应保存到内容工作流。
4. 检查 MP3 字节与摘要，在参考设备上验收播放、字幕、图片辨识和无障碍使用。对获准组合发布不可变内容版本。
5. 国家、年龄、语言及客户端渠道逐项取得准入结论；单一组合的批准不扩展至其他组合。
