# 练习安排的跨日刷新与未提交选择保护

2026-10-03。平台 v0.46，原生壳 0.2.8；没有变更数据库 schema 32、服务端额度规则或既有签名练习。

## 已实现行为

- Web 和原生共用服务端家庭日刷新间隔：最长 5 分钟，临近家庭午夜时更早重新读取；失败约 60 秒后重试。Web 可见/焦点变化和原生前台变化触发重新确认，后台不发周期请求。
- 成功读取只更新今天的快照，不调用 PATCH。只变更用时或生成时间时，当前页面未提交的上限和确认勾选保留。家庭日、时区、分龄、版本、生效安排或采集状态变化时，旧勾选立即失效，不能用旧确认保存新日期的安排。
- 网络、5xx 或 429 读取失败可保留原快照及草稿，页面明确显示“上次确认的安排”，控件与客户端均拒绝保存；成功重读后才开放。身份失效、其他明确拒绝或响应作用域不匹配清除快照。离开页面后的迟到响应不能恢复画面。
- 草稿仅存在页面内存。原生 App 的隐私遮罩可能卸载此页，重进时会重新读取；本批不承诺跨进程或页面离开的草稿恢复。
