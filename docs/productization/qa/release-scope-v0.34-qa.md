# v0.34 市场准入工程验收

日期：2026-10-01。范围：本地家庭服务的国家 × 年龄档 × 内容语言 × 平台矩阵；不构成任何国家的发布批准。

## 已核验

| 检查 | 结果 |
|---|---|
| 空矩阵、无效规则、缺少独立审批引用、重复规则 | 拒绝加载或全部关闭 |
| 美国/9–11 岁/英语/Web 单条模拟批准 | 只允许完全匹配组合；邻近国家、年龄、语言、iOS 均拒绝 |
| 注册、建档、开始新练习 | 服务端分别执行准入；规则移除后不再签发新练习 |
| 原生注册平台 | 批准矩阵模式必须提供 iOS/Android；Web 不接受伪装原生 |
| 本地开发地区 | 仅虚构 `ZZ`；历史家庭迁移默认为 `ZZ`；真实国家代码开户返回 `MARKET_NOT_OPEN` |
| 本机运行服务 | `/api/health` 返回 v0.34.0 和 local-development；对 `US` 开户实际返回 HTTP 403 / `MARKET_NOT_OPEN` |
| 自动回归 | 293/293 业务测试、14/14 HTTP 测试、Web/工作台构建、移动端类型检查、iOS 与 Android JS 包导出通过 |

第一次 HTTP 运行在受限沙箱中因本机端口 `EPERM` 失败；允许测试进程监听本机回环地址后，14 项全部通过。第一次业务回归因旧迁移测试仍固定预期 19 而失败；将迁移 27 列入该测试的延迟版本后，完整 293 项通过。以上不是产品故障。

## 尚未取得的证据

- 首发经营主体、国家组合和产品/法务/安全真实签署；审批引用目前只是可追溯字符串。
- 生产发布清单的读取、签署验证、审计及防回滚；正式服务仍在启动处关闭。
- 居住国家声明与商店/支付地区等来源的核对、旧家庭重新确认、未成年监护验证。
- 规则撤回对已签发离线授权、进行中会话及家长通知的处理。
- 独立 PostgreSQL 受限运行角色本批未重跑；原生设备测试未完成。

因此 D01 工程入口已建立，但真实家庭受控试用与商业上市仍不能开放。执行责任和后续步骤见[准入契约](../RELEASE-SCOPE.md)。
