# 开始邀请的安排刷新与事务校验

2026-10-03。平台 v0.46，原生壳仍为 0.2.8；schema 32，无新增数据库迁移、原生依赖或安装包。

## 实现

Web 独立懒加载邀请和原生邀请复用安排读取客户端。初读、刷新、暂时故障期间不能开始；拒绝参加仍可使用。周期读取最长 5 分钟，临近服务端家庭午夜更早，前台恢复主动重读。数据变化展示更新提示，休息日、额度不足、采集停止和年龄变化都不沿用旧开始按钮。无刷新触发的 POST。

新版开始请求包含 `practice-start-review-1`：家庭日、设置版本、年龄/语言、当前上限和确认/预留/可用额度。新会话创建事务内重新比较；不匹配返回 `409 PRACTICE_PLAN_CHANGED`，且无会话插入或登录凭据轮换。批准矩阵的新会话缺少快照返回 `428 PRACTICE_REVIEW_REQUIRED`。开发预览兼容历史请求；原样幂等重试与匹配活动会话恢复保留既有会话及签名，不能改写期限或额度。用旧幂等键发送新快照会冲突。

快照是客户端安排一致性信息，不是可信的孩子身份、法律同意或研究意愿证明。当前正式入口仍关闭，真实监护验证和内容/地区批准不被此机制代替。
