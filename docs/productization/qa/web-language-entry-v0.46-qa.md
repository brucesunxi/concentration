# 家庭网页首次语言入口验收

2026-10-02，平台 v0.46.0。网页与原生端共用已支持语言选择规则；首次访问只在英语与简体中文之间选择，不把繁体中文自动改写为简体中文。家长仍可在入口手动切换，已保存的本机选择优先。

## 实际浏览器验收

- 用隔离 Chrome、全新浏览器存储和 `zh-CN` 语言打开构建后的家庭网页，首页为简体中文，文档语言为 `zh-CN`。
- 用全新存储和 `zh-TW` 打开同一网页，首页为英文，文档语言为 `en`；手动切到简体中文后刷新，页面保持中文，本机偏好保存为 `zh-CN`。
- 原有英语虚构家庭流程也通过：建档、320px 小屏、一次正式步骤、服务确认与同日休息提示；390px 手机入口的英文错误登录仍正确。Web 构建和 TypeScript 检查通过，离线入口文件为 1,468,246 字节，低于 1,500,000 字节预算。

## 范围

当前仍只有英语与简体中文内容；其他语言会落到已支持语言，不代表已完成当地母语、适龄或法规审查。此项不改变后端市场准入、监护许可和 Vercel Authentication 保护。
