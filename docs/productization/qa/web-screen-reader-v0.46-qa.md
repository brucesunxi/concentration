# 网页读屏操作：显式选择与单独记录

2026-10-02。本批让家庭网页在开始每次练习前明确选择普通操作或读屏操作。浏览器不能可靠识别是否正在使用屏幕阅读器，所以选择只对本次会话生效，不写入家庭档案或推断孩子的能力。

读屏方式只开放没有单题倒计时的“找一找”和“记一记”；限时视觉题的选项在界面禁用，服务端也拒绝此类请求。会话计划、输入事件、课程进度、自动调难度、家长历史和周回顾均保留独立条件。同一设备若已有另一操作方式或另一任务的未结束会话，服务端要求先处理原练习，不把新选择悄悄接续到旧会话。网页与原生端的动画帧延迟不会被当作无倒计时读屏题的错误；素材未就绪、后台、中断和总练习期限仍按原保护处理。网页新题焦点落在标题，记忆题收起材料后焦点移到第一个答案选项。完成页及两端家长历史用“读屏正式步骤”描述，不显示普通输入的正确率或能力变化。

工程核验：任务协议与服务端专项通过；347 项业务测试、18 项 HTTP 回归与两端类型检查通过。隔离的 Chrome 家庭流程走通显式选择、键盘激活目标、找一找的新题焦点、记一记收起材料后的答案焦点、服务端同步与读屏结果文案；同时检查限时任务读屏选项不可用。Web 构建及离线壳体积门槛通过。浏览器自动化没有运行真正的屏幕阅读器。

这仍不是读屏训练效果、WCAG 符合性或各浏览器和辅助技术组合的验收。真实设备上还需检查 NVDA、JAWS、VoiceOver、TalkBack 的焦点顺序、语音混播、记忆题材料隐藏、离线恢复与两语言的可理解性。读屏记录暂不推进四任务基础课程；正式开放前需由方法与无障碍负责人设计完整的替代课程并完成研究。
