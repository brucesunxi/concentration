# 家长密码变更的浏览器纵向验收

2026-10-07。隔离本机家庭服务与 Chrome，所有名称、密码和档案均为测试数据。新增可重复的浏览器验收，纳入 `npm run test:browser` 和 GitHub `Family quality`。

在完整练习、资料撤回与删除、重新登录之后，测试再建一份虚构孩子档案并打开同一浏览器上下文的第二标签页。家长在 320 像素宽度的账号页面输入旧密码、新密码与确认；不一致时提交保持禁用，修正后才能更新。成功后两个标签页都回到登录页面，旧家长界面消失；旧密码被拒，新密码登录成功，刚建立的孩子档案仍在。窄屏密码表单没有横向溢出。

本机完整浏览器流程通过；既有服务端测试继续覆盖账号事务、旧凭据撤销与进程重启。此项证明当前 Web 开发预览的交互与浏览器标签页行为，不证明原生设备、正式身份恢复、OIDC、监护核验或真实家庭环境。测试期间曾用非精确文本匹配把登录按钮“Open family space”误判成旧导航；最终断言直接检查家长应用容器已卸载，避免该假阳性。
