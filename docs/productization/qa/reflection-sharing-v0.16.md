# v0.16 生活回顾自主分享验收

日期：2026-09-30。平台 0.16.0，任务引擎 2.0.0，源内容 0.7.2-preview，原生应用版本 0.2.0。仅记录工程验证，所有页面资料均为隔离环境中的虚构家庭。

## 结论

Web 与原生代码已接通逐次分享选择：默认不保存答案，明确分享后家庭可读，可撤回答案并清除历史动作中的副本与派生摘要。旧客户端无法省略选择；新客户端拒绝无分享契约的旧服务。独立青少年身份、逐成员可见范围、全球政策、真实家庭理解测试与原生设备验收仍未完成。

## 浏览器与接口联验

环境为本机 4225 隔离服务，Codex 内置浏览器，虚构账号 Sharing-QA-016；英文档案 River QA（15–17），中文档案验收小树（6–8）。测试与正式开发资料隔离，凭据不进入此证据目录。

| 操作 | 实际结果 | 验证方式 |
|---|---|---|
| 英文第一份回顾 | 选了三个答案，保持默认不分享；结束后只显示答案未保存 | 实际页面；随后家长 API 导出确认目标与动作均无答案 |
| 英文第二份回顾 | 新回顾重新默认不分享；选择明确分享后展示家庭可见说明，确认保存三个答案 | 实际页面；家长 API 导出与页面选择一致 |
| 撤回说明 | 展示不可恢复、旧副本无法收回及目标保留；取消后仍保留答案 | 实际打开并取消确认界面；没有在浏览器点击最终删除 |
| 移除已分享答案 | 目标和历史导出不含答案，包含撤回标记 | 本地 API 对该虚构记录执行；结果存入 api-proof.json |
| 家长最终页面 | 使用家长视角说明，分别显示已撤回与从未保存，不显示答案 | 最终构建实际页面 |

没有抓取浏览器网络来声称逐包验收：无答案请求的证据来自共享请求生成器/客户端测试，同一浏览器产生的服务记录通过独立 API 导出核对。自动 HTTP 测试另覆盖原生令牌传输，但这不是原生 App 触摸与设备流程验证。未测轮询刷新延迟上限，也未声称另一台已打开设备立即清除画面。

## 更新恢复发现

在测试页面保持打开时原位重建静态文件，旧运行文件继续引用已经替换的懒加载模块，导致错误边界；普通刷新重复出现。工作进程按现有设计等待旧页面关闭，不强制接管正在进行的练习。本批补充双语提示：先完成或暂停其他页面练习，关闭本站标签页，再联网重开；尚未保存的选择需要重新填写。

取得更新检查后关闭本次测试标签页，再重新打开同一地址，家长目标页面与中文流程恢复正常，已保存记录未丢失。这验证恢复路径，不表示已实现无缝升级。正式部署还须保留旧版本静态文件、原子切换发布及完整更新/多标签页矩阵；不应在有真实家庭使用时直接覆盖旧构建。
