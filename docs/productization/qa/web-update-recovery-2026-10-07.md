# 网页更新后的延迟页面恢复

2026-10-07。本地 375 像素浏览器复现：旧版离线外壳仍提供旧首页，进入「接受邀请」时该版本的延迟脚本已不在当前服务器，错误页的普通重载重复打开旧首页，无法恢复。此项会影响长期打开的家庭标签页，不是账号或记录丢失。

当前构建把所有延迟页面的 JavaScript 和样式纳入校验后的公共离线外壳；旧版所需的代码随其外壳保留，历史大幅刺激图不因本次改变进入初始下载图。更新后的错误页通过带查询参数的在线导航避开旧外壳的首页缓存；完成当前外壳检查后移除临时参数，避免以后离线重开仍携带绕过缓存的地址。更新不强制接管其他正在练习的标签页。

专项验证：离线清单覆盖延迟代码但排除历史大图，发布校验拒绝遗漏延迟模块的外壳；当前 Vercel 构建通过发布制品检查。首页静态依赖为 **1,209,223 字节**，离线外壳为 **1,351,921 字节**，均小于各自 1.5 MB 限额。本地以查询参数读取当前构建后，地址恢复为普通首页，「接受邀请」表单可完整加载，手机宽度无横向溢出。完整业务回归 **409/409**、HTTP 回归 **19/19**、类型检查与构建通过。新增隔离 Chromium 用例实际中断一次延迟脚本，验证错误页在线重载、临时参数清理及邀请表单恢复；既有家庭浏览器流程同时通过。此用例没有模拟旧新 Service Worker 交接的全部生命周期或跨浏览器离线重开。线上部署另行记录。
