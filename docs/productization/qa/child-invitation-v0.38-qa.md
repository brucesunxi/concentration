# v0.38 孩子自主开始邀请验收

日期：2026-10-01。范围为本地开发 Web、原生源码和独立合成家庭浏览器测试；不涉及真实家庭。

![合成家庭中 6–8 岁孩子的开始邀请](child-invitation-v0.38.png)

## 本批结果

- 两端推荐练习和四个任务入口先显示分龄双语邀请，再决定是否新建会话。邀请有明确的“开始”和“稍后再说/暂不参加”，家长界面提示把屏幕交给孩子；网页关闭按钮与 Esc 同样取消。档案创建文案不再替孩子宣称已经愿意参加。
- 独立本地测试服务中，6–8 岁中文档案打开邀请后选择“稍后再说”，返回首页；随后家长周回顾显示已开始但尚无确认结果的会话为 0。再次选择“我想开始”才进入任务规则示范，随后从示范页提前结束并由服务端确认。孩子作用域再次打开邀请时不出现家长提示。
- 同一合成家庭的 15–17 岁英文档案显示 `You decide whether to begin`、`I choose to begin` 和 `Not taking part now`，拒绝后回到首页。浏览器实测覆盖中文儿童与英文青少年两种代表性文案；其余组合通过共用分龄双语文案和两端类型检查接入，尚未由目标用户逐项验证理解度。
- `npm run check`、`npm run mobile:check`、`npm test`（296/296）、`npm run test:http`（14/14）、`npm run build` 和 `npm run mobile:bundle` 通过。iOS/Android Hermes 运行代码均含本批开始与拒绝文案；这只证明源码进入运行代码，不证明已安装。最终 Web 离线入口 1,490,568 字节，低于 1,500,000 字节预算；本地健康接口返回 `0.38.0`。首次 HTTP 执行因浏览器验收服务占用固定测试端口而失败，停止该服务后重跑全绿。

## 仍待验证

孩子实际操作与自主拒绝需要适龄研究观察；本次点击不能证明屏幕前的身份，不能替代监护核验或研究同意。后续已生成包含本批代码的 [Android arm64 本地测试包](native-package-v0.38-qa.md)，但原生设备尚未安装和交互验收。真实供应商、地区审批、独立 PostgreSQL 套件、内容与声音的真人审核仍是发布门槛。
