# v0.46 家庭 Web 实际浏览器验收

2026-10-02，源码 `b075574`。用本机隔离数据目录、`APP_MODE=local` 和打包后的 Web 页面，在 Google Chrome 154 的无界面浏览器中验证；全部使用虚构家庭与孩子资料。服务运行在 `127.0.0.1:4197`，未连接 Neon 或线上家庭空间。

## 实际走通

- 英文家长首次建立家庭、创建 6–8 岁孩子档案，回到小岛登录后可看到课程、四类任务和生活小目标入口。
- 点击推荐练习，出现孩子自己选择的邀请页；点击开始后，进入规则示范，固定语音播放按钮和随时休息、退出入口可见。[邀请页](browser-invitation-v0.46.png) · [规则页](browser-rule-v0.46.png)。
- 另一虚构家庭在规则页选择「Not today」，服务核对并保存未完成正式步骤的记录；结束页明确提示休息和屏幕外的小活动，没有把这次选择表述为成绩。[退出后页面](browser-decline-v0.46.png)。
- 390 × 844 手机视口的英文初次进入页没有横向溢出（文档宽度与视口同为 390px）；布局、表单和确认说明均可阅读。[手机入口](browser-mobile-entry-v0.46.png)。
- `npm run build:vercel` 通过，Web 入口体积检查为 1,463,595 / 1,500,000 字节。

## 范围边界

这次没有完成整轮正式练习、完成后再次邀请的当天休息提示、真实设备读屏/触摸、语音听感、Safari/Firefox 或线上 Neon 环境验收。当前页面和内容仍是开发预览；虚构资料的浏览器流程不构成真实家庭可用性或训练效果证据。
