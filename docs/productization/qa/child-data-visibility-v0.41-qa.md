2026-10-01。本批仍是仅用虚构资料的本地开发预览，不代表已获准招募真实家庭。

## 已实现

- Web 与原生 App 共用四年龄段、简体中文和英语的说明文案。孩子首页在练习区上方提供入口；说明将练习结果、家庭创建者可导出的逐次操作、生活目标状态和可选分享的三个回顾答案分开。
- 回顾答案默认不保存；主动分享后可移除。说明明确：移除影响后续查看和导出，已被看到或下载的副本不能收回；共用设备屏幕也可能被旁人看到。没有承诺独立青少年账号或绝对私密。
- 说明本身不发起新数据请求，也不更改既有权限或采集行为。后台分享与导出的实际规则仍由原有权限检查执行。
