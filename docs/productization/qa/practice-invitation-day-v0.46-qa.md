# 开始前当天状态提示验收

2026-10-02。目标是在每次新练习选择之前，让 Web 与原生端读取同一个服务端家庭日快照，避免孩子已经练过或今天已暂停时仍直接看到无上下文的“开始”按钮。

## 行为

- 页面打开前读取当前孩子的 `/api/children/:id/practice-limits`，校对契约版本和孩子 ID；身份或档案在读取期间变化时忽略晚到结果。
- 今天已有确认用时但仍有余额时，显示可以先离开屏幕、在生活里试策略的双语提示；孩子仍可选择开始或稍后再说。
- 暂停、停止采集、尚有未确认练习或余额不足 5 秒时，开始按钮不可用，并可进入「练习与休息」查看安排；未确认练习由家长从恢复入口处理。实际创建请求继续由服务端重新计算额度。
- 读取失败时不展示可能过时的安排，不创建新会话；原有错误入口负责显示连接问题。
