### 新增八项检查的实际断言

1. RFC 6238 六组时间点 × SHA-1/256/512 向量匹配，包括 2038 年之后的计数。
2. 成功使用的验证码不能再用；过期会话和停用身份不能继续读写。
3. 同一验证码并发登录只有一个成功；失败次数与锁定状态在数据库中保存。单元检查没有额外模拟锁定期间的进程重启。
4. 重复创建返回同一稿件；同请求标识更改请求内容被拒；错误职责、旧版本修改被拒，来源内容保持原样。
5. 修改已配音文案而保留旧音频时被拒；明确移除后可保存；冻结后不可编辑。
6. 审核退回后修改生成新稿次/摘要，旧批准留在历史里但不能满足本轮双审。
7. 勾选检查不完整时不能批准；超出最近验证窗口须重新验证；停用已批准的审核人后不可继续发布。
8. 双审签名预览只能用于本地；新计划使用新版本、旧计划保留原引用；召回后连相同事件的重复补传也拒绝，重复召回不重复登记内容召回审计。

### 真实进程接口

测试独立使用家庭端口 4201、工作台端口 4204 与临时 PGlite 数据目录。四角色通过真实 HTTP 登录，检查家庭/管理凭据隔离、错误 Origin、CSRF、Bearer 拒绝、动态验证码重用、缺少 If-Match、职责与幂等约束。

创建草稿后分别审核、发布，并创建家庭练习确认计划引用新的摘要。工作台媒体响应为 `no-store`。停止并重启服务后，原管理会话仍在有效期内，稿件、两条审核与发布摘要保留；随后召回、幂等重试、检查家庭会话拒绝和退出后的失效。

接口测试不是公网安全测试、实际 PostgreSQL 负载测试或全部设备召回演练。

## 浏览器实际操作

环境：Codex 内置浏览器，工作台 4210 / 家庭 API 4207，独立临时测试库；没有向主家庭库添加模拟批准。四账号显示名均带“验收专用”，审核依据明确写明不是专业审稿。

| 操作 | 页面观察 |
|---|---|
| 编辑登录，选择搜索 / 6–8 岁 / zh-CN 来源 | 建立 `99.0.0-browser-qa` 草稿 |
| 修改名称、暂不保存 | 冻结、新版本、刷新、退出受未保存保护 |
| 保存后冻结 | 显示第 2 稿、操作版本 3 和完整候选摘要 |
| 方法审核角色提交通过 | 保持“待双人审核”，显示第一条依据 |
| 语言审核角色提交通过 | 变成“可发布预览”，保留两条不同角色依据 |
| 发布角色核对完整摘要并发布 | 显示“预览已发布”，出现召回表单及发布记录 |
| 填写摘要与原因召回 | 显示“已召回”，操作版本 7，出现重试清理入口 |
| 加载最终前端构建并重新打开稿件 | 召回状态、两条审核、发布与召回记录仍可读 |
| 打开第二页面，在第一页退出 | 两个页面都回到登录界面，管理内容视图清除 |

候选摘要：`4f3fcfa93d00ae228d2972b7f8ccd36561b1f17e9c63ad1b08c72f371029fccc`。

媒体控件可显示图片并启动固定音频播放，但此流程不构成声音自然度、母语发音或音文适用性的专业听审。工作台尚不能直接运行该候选版本的整段儿童任务。

完整编辑至召回流程运行于本批初始前端构建；随后仅补充迟到队列响应的身份保护，最终构建已复验刷新重读与跨页退出。最终完整 HTTP 检查包含请求头规范化的小修复。未将这两个修复表述为全浏览器重新走遍所有功能。

## 构建与兼容性

- 家庭入口静态依赖合计 **1,470,720 字节**，通过 1,500,000 字节预算；[明细](web-budget-v0.13.json)。工作台是独立入口，不计入家庭入口预算。
- 家庭离线运行版本为 `154cdfaefc72a57c4d66bb081d4219c37db53e706ab4cd5d3c4cb1c71560e34b`。前一批 v0.12 的浏览器断网证据属于当时构建，本批没有重新宣称通过完整离线设备矩阵。
- 工作台脚本 `index-CLFKYYxH.js`，样式 `index-B1kPe8_D.css`；完整摘要见追溯清单。
- 本批只导出新的移动运行代码，没有重建或安装独立 `.app` / `.apk`。`dist/mobile-native/v0.11/` 仍是历史产物；旧包不能自动获得新内容通道支持。
- 全部声音沿用固定本地文件；没有调用付费语音服务，也没有向运行时加入实时模型。
