# v0.29.1 家庭流程与零正式步骤记录验收

2026-10-01。使用独立的本地开发数据目录和虚构家庭，检验家长建立空间、孩子短练习及家长回顾。此证据只覆盖本机开发体验；页面中的本地确认不构成正式监护同意，也不能用于招募真实家庭。

## 交付变更

- 当孩子只熟悉规则或中途结束、尚未完成任何正式步骤时，Web 与原生总结明确说明这一点，避免把示范说成正式训练结果。
- Web 与原生家长记录将此类提前结束的记录标注为“尚无正式步骤”；原生端不再显示没有分母意义的 `0/0`。
- 周回顾把每日数量称为“已确认练习记录”，并在该策略没有完成正式步骤时说明“示范不计入表现”。这里仍保留提前结束的事件记录，供家长理解过程。
- 英文周回顾和历史翻页按数量显示单数或复数；单条记录不再写成 `1 attempts` 或 `1 records`。
- 本机健康接口从根包读取版本号，不再保留与产品版本脱节的硬编码值；常用服务 `127.0.0.1:4181` 已返回 `0.29.1` 并提供最终 Web 构建。

## 浏览器端实测

隔离数据目录为 `/private/tmp/focus-family-e2e-v030`，没有触碰日常家庭数据。在浏览器中用虚构家庭建立空间、添加 6–8 岁中文孩子，打开推荐的“森林寻宝”；规则音频控件进入播放状态。完成一条示范后暂停，刷新页面仍停在可恢复的休息状态；选择“今天到这里”，服务确认后返回家长空间。周回顾显示完整练习 0 次、提前结束 1 次；记录卡和策略摘要均清楚标明没有完成正式步骤。最终 Web 构建在独立端口 `127.0.0.1:4195` 复核，英文页面分别显示 `1 confirmed practice record`、`1 attempt` 和 `1 record on this page`。

## 尚未通过的发布门槛

本批没有真实儿童可用性研究、固定语音的完整覆盖与听审、内容专业审核、正式监护同意流程、原生安装包设备交互验收或独立 PostgreSQL 运行验证。v0.29 的 iOS 测试包仍因缺少 Keychain 权限无法完成登录与声音设备验收；本批代码导出不能替代修复该签名并重新制作安装包。
