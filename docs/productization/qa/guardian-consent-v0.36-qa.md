## 已通过

- 本地勾选不能开启批准地区的采集；正式模式建档默认无许可。缺少适配器、凭证字段不匹配、过期、未来核验时间和重放均拒绝。有效合成证明绑定家庭创建者、孩子、居住国家、年龄档、语言、家庭练习用途、告知文本摘要与当前准入身份。
- 到期或准入身份变更后，许可状态回到未激活；撤回同时封闭孩子采集并记录撤回时间。导出包含脱敏历史，不包含原始核验引用。家长协作和生活目标共用当前许可判断。
- 数据库迁移 29 可在 PGlite 重复运行；14 张家庭表列入运行角色隔离清单，新增许可表有家庭/孩子/创建者的数据库约束。真正的独立 PostgreSQL 行级权限和并发套件本批**未运行**。
- `npm test`：294/294；`npm run test:http`：14/14；`npm run build` 和 `npm run mobile:check` 通过。接口测试覆盖当前本地服务；正式核验方法没有 HTTP 路由，因此不应把 14 项接口测试解释成供应商端到端验收。
