# v0.33 本机未同步记录留存验收

日期：2026-10-01。范围：家庭 Web 的 IndexedDB 与原生 App 的加密 SQLite；使用虚构会话和本机数据。

## 已实现

- 新未同步练习日志从首次写入计时，7 天后在下一次本机访问时删除事件与对应离线恢复记录，并保存轻量封闭标记，阻止旧页面或旧会话再次写回。
- 家长空间在记录到期前 24 小时提示数量、清理时间和在原设备联网检查恢复的操作。界面不承诺已过期记录仍会保留。
- 两端分别保存已见过的最高设备时间，时钟回拨不能延长既有日志的保留期。Web 升级到 IndexedDB v3；原生 SQLite 启动时补充创建时间字段。
- 旧版本日志没有可信创建时间，为避免无提示丢失，升级时从升级当天开始新的 7 天窗口。这是兼容迁移的明确例外。

## 验证与范围

专项验证覆盖 Web 升级、代次保留、临近到期提醒、7 天边界、时钟回拨、过期后的离线恢复与旧页面重写阻断；SQLite 验证封闭、删除离线恢复和保留较新日志。`npm test` 290/290、`npm run test:http` 14/14、Web/工作台构建、移动端类型检查与 iOS/Android 代码打包均通过。

设备关闭时没有后台清理能力；下一次启动或访问本机日志时执行。原生加密 SQLite 的迁移与界面提醒尚需在签名正确的 iOS 和 Android 真机上核验。正式监护同意、人工内容批准和真实 PostgreSQL 权限套件仍是独立发布门槛。
