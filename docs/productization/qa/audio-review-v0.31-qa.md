# v0.31 逐文件声音审核约束

日期：2026-10-01。范围为本地内容工作台的任务内容审核和预览发布；家庭正式市场仍关闭。本批没有为任何候选声音填写真实专业批准。

## 变化

- 审核人打开当前冻结稿后，逐段完整播放已配置的 MP3。页面仅在从头播放到结束且未快进时，把对应 SHA-256 加入本页的已听清单；换稿次或换内容摘要后不能沿用旧播放状态。
- 通过审核时，服务端要求提交的清单与当前稿全部声音文件摘要完全一致，拒绝缺项、旧文件、额外文件和重复摘要。审核记录保存该清单，签名依据保存清单摘要和试玩证据。
- 发布时重新检查两位审核人的清单。此前只勾选泛化“素材已检查”的旧审核不能用于新的发布；作者须开启新稿次，安排重新试玩和双审。退回修改仍可直接提交问题，不要求先听完。
- 此流程提供的是可追溯的人工声明和客户端播放完成记录，不能从浏览器事件证明真人听觉、母语判断、音质或孩子理解。真人审核人必须写明实际判断；真实设备播放与适龄研究仍独立进行。
