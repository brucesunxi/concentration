# 家庭档案导出的一致读取

2026-10-07。长期使用的档案可能跨多页包含练习、步骤、生活观察、监护确认和生活目标。原导出在数据库默认的逐语句读取隔离下，分页和不同栏目可能读到不同时刻的资料；家长拿到的文件因而可能把新步骤与旧状态拼在一起。

现在两种服务端导出格式都在**家长身份验证之前**开启 PostgreSQL `REPEATABLE READ` 事务，身份检查、孩子档案、使用额度、各栏目分页与生活目标共用同一事务。家庭边界仍先锁定，导出期间撤销或删除须遵循该边界；导出完成后才返回文件。共享事务层禁止在普通事务开始后悄悄把内层请求“升级”为一致读取。原先额度部分调用独立读取路径，现已移入同一事务。

验证：分页档案的 205 条观察、205 条监护记录、206 个目标等与旧格式逐字段一致；两种导出确实请求一致读取；本机 PostgreSQL 兼容引擎确认事务隔离级别为 `repeatable read`。类型检查、Vercel 构建、全量 410 项业务回归与 19 项 HTTP 回归通过。生产 Neon 上的并发写入、连接耗尽、较大档案和备份恢复仍须在独立测试分支演练，不能由兼容引擎证明。

当前单文件服务端上限为 100 MB，网页和原生客户端各有更低的内存/分享限制；这次只修复同一文件的读取一致性，分批导出仍是后续交付。
