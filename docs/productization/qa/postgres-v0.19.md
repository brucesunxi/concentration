# PostgreSQL 隔离与故障验收

日期 2026-10-01。应用版本 0.19.0；迁移版本 17。本次使用独立容器中的虚构家庭，未迁移真实家庭数据。家庭与工作台分别使用非拥有者、非超级用户、无 `BYPASSRLS` 的数据库角色。

## 本次结论

真实 PostgreSQL 16.14 的家庭隔离、作用域清理、并发写入、召回与服务重启已通过范围内验证。断连测试曾触发借用连接在查询间隙的未处理异常；已补上连接级错误监听，回滚并丢弃失效连接，复验通过。

| 检查 | 结果与范围 |
|---|---|
| 迁移与身份 | 三个并发迁移、重复准备；17 个唯一版本；拒绝高权限身份、交叉角色与额外策略 |
| 读取与写入隔离 | 无上下文拒绝；十张已填充家庭表漏写筛选仍只返回本家庭；兄弟姐妹隔离、跨家庭写入及混合家庭孩子凭据被拒 |
| 连接池 | 80 次交替家庭并行事务，结束后无上下文残留；SQL 错误回滚原有昵称 |
| 注册原子性 | 模拟令牌保存失败，家庭记录也回滚 |
| 断连 | 终止当前数据库连接，未提交更改消失；后续请求使用健康连接，默认作用域为空 |
| 同时保存 | 12 个相同观察、2 次孩子进入、2 组事件上传、8 次结算；一份观察、一份成绩和一次课程推进 |
| 生活与隐私 | 重复目标不重复创建；停止采集撤销孩子令牌并阻止旧上传；导出保留既有记录；删除级联清理后不能补传 |
| 数据库权限 | 家庭不能读工作台、写内容或迁移表、创建表、清空表、关闭行级保护或切换拥有者；工作台不能直接读取家庭表 |
| 召回 | 未召回摘要不能调用专用清理；已召回可重复清理，活动练习关闭，旧事件被拒 |
| HTTP 与管理命令 | 受限角色启动、重启后档案保留；Web/原生/工作台凭据不混用；工作台创建身份、验证码登录和草稿保存 |

## 证据边界

并行请求测试不等于负载或持续运行测试；终止单个数据库连接不等于托管数据库切换或备份恢复。工作台本轮验证独立角色、基础 HTTP 编辑和受限召回；其完整审核与媒体流程此前主要在 PGlite 验证。未验证全部浏览器、真实移动设备、生产地区与真实家庭。
