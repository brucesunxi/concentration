# 家庭 API 匿名汇总验收

2026-10-06。对应 D07 生产运行差距中的运行观测；本批是操作员只读汇总工具，不代表已完成告警和值班。

## 验收范围

- 输入支持 Vercel JSONL 的 `logs[].message` 与直接应用 JSONL。Vercel 顶层重复的 `message` 不重复计数；相同请求编号的相同事件去重，互相矛盾的事件两条均不进入指标。
- 仅接受应用版本 1 的固定 `FAMILY_HTTP_REQUEST` 字段和服务器生成的路径类别。原始 URL、儿童标识、平台消息、请求编号与错误文本不会出现在汇总结果。
- 家庭流量与 `/api/health`、`/api/ready` 探针分开；业务拒绝、服务器错误和连接中断分开。错误率/P95 少于 20 个相应样本、P99 少于 100 个完成请求时不生成这些统计值；遇到来源条数上限、格式错误或编号冲突时同样停止计算。
