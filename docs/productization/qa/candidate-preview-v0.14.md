## 结论

冻结候选可通过家庭 Web 的真实任务界面完整试玩。服务端核对事件后保存独立回执，审核与发布要求创建者本人、当前稿次、当前内容摘要且完整结束的记录。退回、撤回、召回、到期和身份变更的边界已有检查。普通家庭的完整搜索练习也在本批最终任务代码上回归通过。

使用独立临时数据库与虚构角色完成验收。**源内容仍为 32 份未审核开发材料，真实专业批准 0 份。** 工作台批准仅用于流程测试，没有发布到主家庭库或任何商业市场。声音控制验证不等于听感或专业语言审阅。

源文件、构建、移动运行代码、截图与日志摘要见 [可追溯清单](candidate-preview-runtime-v0.14.json)。执行环境 Node 26.5.0；没有覆盖所有最低支持版本或设备。

### 新增断言

- 没有试玩、其他身份的试玩、未结束或提前结束的试玩不能批准；本人完整当前稿可批准。
- 开始请求幂等；同一键改变参数失败；结束后同一事件重试返回原回执，不同事件不能替换。
- 作者撤回后新稿次失效，即使重新提交的内容摘要相同也不能复用旧记录；未结束 31 分钟后拒绝读取和核对。
- 32 个任务/年龄/语言组合 × 3 个难度，共 96 份计划通过浏览器端核验函数和服务端完整回放。这是合成事件测试，不是 96 次浏览器操作或儿童测试。
- 改包、改计划、重算被篡改计划摘要和改变预算均拒绝。
- 迁移后 `preview_id=NULL` 的既有 ready 批准不能直接发布；错误角色不能撤稿，作者开启新稿并取得新证据后可发布。
- 召回后原候选即便已结束也不能重新读取或再次提交核对。
- 候选协议测试没有生成家庭或家庭会话表记录；正常家庭流程由独立回归覆盖。

过程中出现过测试夹具使用真实时钟、以及新增测试预期错误码拼写不符的问题，均已修正；本页引用的是最终通过日志。

## 保留的限制与下一步

- 至少一次协议完整回放不是人的资质、真实操作、物理响应时间或训练有效性的证明。签名只绑定所述内容与证据。
- Web 候选页面在线、未结束操作只在页面内存；刷新不恢复，明确丢弃后可重新准备。没有增加家庭数据采集或外部语音请求。
- 当前仅本地工作台身份、文件权限保护密钥与 `LOCAL` 发布；生产 SSO/KMS/审计、保留期限、分页及媒体导入待实现。
- 原生 App 安装包和真机验收未在本批完成；Hermes 导出不代表旧安装包自动更新。
- 全部专业审稿、完整英语和分龄声音、全球地区政策、青少年共享、支付与商业上线、可用性和效果研究仍在完整目标范围内。
