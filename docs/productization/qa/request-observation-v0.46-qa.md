## 实现与专项证据

家庭处理层与 Vercel 入口共享同一响应采集器。前者记录接口技术结果，后者在初始化前开始计时，失败也返回响应编号。完成与断开只记录一次；响应日志不保留原始路径、查询、正文、身份、原始错误或凭据。

6 项业务专项通过：固定路由分类、双层响应编号与时间、断开/未知码及非法元数据、安全静默与日志故障、运行配置，以及实际调用 Vercel 初始化失败后的两次独立响应。真实进程 HTTP 专项通过：虚构家庭建档、带合成私密查询和正文的校验失败、原生凭据拒绝；返回 header/错误 body/日志中的 requestId 相同，每个请求只有一项记录。合成家庭名、昵称、密码、Cookie、CSRF、孩子 UUID 与 Bearer 均未出现在应用 JSON 日志中。

这是应用日志字段的验证，不证明平台请求日志、数据库、代理或供应商没有其他元数据。请求编号与时间也仍属于需要限制用途和留存的运维资料。
