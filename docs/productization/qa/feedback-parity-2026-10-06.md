# 跨端练习纠错一致性

2026-10-06。本轮只修改孩子完成一步后的反馈展示，没有更改任务计划、计时、计分、签名内容包或正式准入。

## 核对结果

- Web 和原生端现在共用同一段结果说明：抑制/监测任务按实际记录区分误点非目标与漏点目标；正确完成时使用当前内容包的策略文字。文案描述本次操作，不推断孩子的能力或原因。
- 搜索任务的目标位置取自该次冻结计划的 `target` 和 `items`，不固定假设某一种图片。原生端现在与 Web 一样显示目标位置。
- 顺序记忆出错时，原生端展示当次计划的正确顺序、图片和名称；示范出错或借助提示后，继续按钮明确写「再试一次」。
- 规则语音、内容审核状态与孩子可使用的素材没有变化；纠错仍为屏幕文字和图片，没有新增纠错录音。

## 工程验证与边界

`npm test` 404/404、`npm run check`、`npm run mobile:check`、`npm run build:vercel` 和 `npm run mobile:bundle` 均通过。专项用例覆盖两类抑制结果的中英文说明，以及目标不是默认图片时的位置计算。构建出的 iOS/Android 运行代码不等于设备上完成了可读性或读屏验收；本轮检查时没有已启动的模拟器或连接的 Android 设备。儿童对纠错文案和图像的理解仍需按年龄/语言进行真实观察。
