# v0.30 固定语音候选素材与接入验收

日期：2026-10-01。范围为本地开发内容，目标用户仍是全球 6–17 岁儿童与青少年及其家庭。本批生成与接入语音候选，不代表母语审稿、儿童理解研究或商业发布批准。

## 交付

- 4 个年龄段 × 2 种语言 × 4 种任务共 32 个内容组合均有与指令文本完全相同的固定 MP3。16 份不同源录音中，13 份为本批 Azure Speech 制作候选，3 份为此前保留的中文儿童录音；声线及文件逐项见[候选清单](voice-candidates-v0.30.json)。运行时不连接实时语音模型。
- 覆盖口径补充（2026-10-06）：这里的“指令文本”指内容包声明的 `copyKey`，不能理解为 32 个组合都朗读了完整任务规则。当前 24 个组合朗读 `rule`，8 个“抑制冲动”组合朗读 `strategy`；后者仍需要阅读或读屏获取目标与非目标规则。`voice:audit` 现分别输出这两类覆盖及规则朗读缺口。
- 六个既有中文儿童内容包保持 0.7.2-preview 与原有摘要。其余 26 个组合使用新增 0.7.3-preview 内容包；新旧版本按内容摘要区分，旧会话仍引用原字节。所有 32 个包均标为未审，仅供本地开发。
- `npm run voice:content -- --dry-run` 可核对待制作台词，`npm run voice:audit -- --out docs/productization/qa/voice-candidates-v0.30.json` 可重建文件格式、摘要和覆盖清单。生成器通过一次性输入读取语音服务凭据；凭据不写入项目文件或 App。
- [内容准备度清单](content-readiness-v0.30.md)列出全部台词和待审步骤；[内容清单](content-inventory-v0.30.json)保存签名和素材校验结果。

## 待验收

1. 中文、英文母语审核人按每个不同台词完整听审发音、自然度、语气和适龄程度；方法负责人核对指令与真实任务规则。审核签名应绑定内容版本和文件摘要。
2. 在目标 iOS、Android 设备和主要浏览器上验证实际播放、音量、暂停与重开、字幕、读屏、听觉可辨识性及静音降级。当前仅验证内容/API 和两平台运行代码导出，没有制作 v0.30 安装包。已在 Expo 配置与现有 iOS 工程声明 Keychain 访问组，并验证配置及 plist 格式；本机没有有效 Apple 签名身份，无法证明权限进入可启动的新包。旧 iOS 测试包仍受 Keychain 权限错误 `-34018` 阻断登录后的音频验收；Android 尚未设备安装。
3. 各年龄和语言邀请家庭在适用研究许可下检验指令理解、疲劳与退出体验。内容审核与市场准入均须单独完成。当前 0 个内容包可正式发布。
4. 既有语音服务凭据曾在对话中提供；产品化前须轮换并纳入团队密钥管理。App 与版本库中不得保存凭据。
