# 原生练习准备失败时保留恢复资料

2026-10-07。移动测试版 `0.2.11`，Android 版本码 `12`、iOS 构建号 `12`。本次修正的是本机存储、素材或解析暂时失败时的资料处置；不改变练习计分、采集授权或服务端结果。

原生端先前在离线恢复资料写入失败、或准备流程遇到非网络异常时，会额外删除该会话的 `offline_resume` 入口。若设备已有一份有效的恢复入口，新的写入只是因空间不足或短暂 I/O 问题失败，这一步删除反而会让已有操作更难恢复。现在非权威失败会停下练习、提示保持联网，并保留现有恢复入口与加密事件日志；创建但未交给界面的运行实例会停止接收新操作。只有服务端明确的撤回、删除、内容召回、会话失效等授权变化继续封闭对应恢复入口，原有七天留存与到期清理规则不变。

本机 SQL 专项模拟旧恢复入口存在时替换写入失败，确认旧入口和事件日志均未变化；相关会话运行、失败写入与授权撤回专项共 22 项通过。全量 `npm test` **419/419** 通过，`npm run check`、`npm run mobile:check` 及 Android/iOS Hermes 运行代码导出通过。

`0.2.11` 的 APK/AAB 已从同一源码提交构建、核对包体与签名；Android 35 模拟器已实际完成从 `0.2.10` 覆盖安装、离线恢复、正式练习、重连补传及家长报告一致性检查，详见[构建交付](android-aab-ci-2026-10-07.md)和[升级验收](android-upgrade-v0.46-2026-10-07.md)。尚未在低存储真机或安装包上制造系统级 I/O 故障，因而这项资料保留修正仍仅有源码和 SQLite 故障注入的针对性证据；iOS 签名和设备验收按既有计划另行完成。保留损坏或无法解密的资料不等于保证它一定能恢复，家长导出仍会把读取失败标为不可用。
