# 本浏览器记录导出与 iOS 启动核对

2026-10-02。此轮继续使用虚构家庭资料；网页发布仍遵守现有受保护预览范围。

## 网页记录导出

家长导出档案时，文件在服务端记录之外加入当前浏览器保留的 `localRecovery` 日志，并写明 `included`、`none` 或 `unavailable`。日志按当前家庭和孩子筛选，导出前重新计算事件摘要；旧版无摘要日志单独标为 `legacy-unverified`。若本机读取或摘要校验失败，界面告知文件只含服务端记录。家长页面说明其他设备须单独导出。

验证：`npm run check`、351 项业务测试、18 项真实本机 HTTP 检查和 Web 构建通过；离线首屏为 **1,474,064 / 1,500,000 字节**。专项测试覆盖旧库迁移、家庭隔离、关闭后的未清除日志以及篡改拒绝。桌面交互通道仍报告 Mac 锁定，故没有把浏览器点击操作算作本轮验收。

## iOS 模拟器

iOS 26.5 的 iPhone 17 模拟器已启动，安装的 `dev.focusisland.family` 测试版可启动并显示[中文家长登录首屏](ios-launch-2026-10-02.png)。这只证明启动与首页渲染。当前保留的模拟器包经 `mobile:verify:ios-keychain` 检查缺少签名团队、应用标识和 Keychain 访问组；本机 `security find-identity -p codesigning -v` 没有可用签名身份。安全存储、登录后页面和练习仍未通过设备操作验收。

该模拟器包并非本次网页改动的原生新包，也不是商店交付包。
