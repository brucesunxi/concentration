## 浏览器实际操作

使用隔离服务 4237、虚构家庭 Guide-QA-018、中文 6–8 岁“陪伴小树”和英文 15–17 岁“Guide Robin”。没有真实儿童资料，没有调用外部语音或模型。

1. 中文当前建议显示第一阶段、0/3 次。切换第三节后显示两步整理的分龄例子。
2. 打开生活建议后，“试试两步整理”已预选，历史仍为 0 个目标。点击保存后才出现 1 个“等待一起商量”的目标。
3. 从第一节再次打开另一建议，原步骤目标仍在、总数仍为 1，没有被替换或自动新增。
4. 交给孩子后，家长课入口弹出家长验证；验证后返回家长课。
5. 切换到青少年档案后，语言和年龄例子随档案变化；选第七节显示个人项目、核对和求助内容。
6. 最终构建在 390×844 视口下显示可展开主题目录，正文无水平溢出；DOM 实测 viewport 390、clientWidth/scrollWidth 都为 375。用 Return 选择第七节后目录收起、正文标题获得焦点。
7. 使用隔离 API 停止青少年档案采集，再刷新页面：仍可阅读，生活建议按钮禁用。
8. 切回中文儿童档案后恢复第一阶段及儿童例子，青少年停止采集状态没有串入。

新版本加载遵守现有 Service Worker 更新机制：页面刷新后仍可能由旧 worker 提供旧入口。检查实际脚本后关闭本站旧标签页并重开，最终入口为 `index-C0591DTb.js`。窄屏目录、英文页面和停止采集检查在最终构建进行；早期中文建议保存/孩子验证截图来自本批初构建，两版的这部分业务代码一致。

## 限制

没有在 iOS/Android 设备上操作新页面：本轮开始时电脑锁屏且无法自动解锁。仅导出新的运行代码；历史安装包的内容不能当作本批原生页面。没有把内置浏览器结果推广到 Safari、Firefox、完整无障碍矩阵或所有年龄/语言组合。

新增家长课尚未接入内容工作台的双审/签名发布。现有 32 个任务包的审核状态没有因本批改变；它们与家长课均不能凭自动检查被认为获得专业批准。母语与适龄审稿、真实家庭试用、日常效果研究、全球市场政策和生产发布条件仍未完成。
