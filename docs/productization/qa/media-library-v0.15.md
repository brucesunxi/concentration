# v0.15 图片与固定语音素材库验收

日期：2026-09-30。平台 0.15.0，任务引擎 2.0.0，源内容 0.7.2-preview，原生应用版本 0.2.0。此页只记录实际工程验证。

## 结论

PNG/MP3 可以通过工作台导入，记录来源与权利声明，生成不可变的原件/交付件引用，换入新稿并接续完整试玩、双审和本地签名发布。HTTP 验证了新增字节发布前不可从家庭读取、发布后可读、进程重启保持摘要，以及召回后拒绝新的公共读取。

浏览器使用独立临时库和虚构编辑，复用项目已有 PNG 和 MP3 完成导入及换稿后的整次搜索试玩。本轮没有新生成图片或录音，没有调用 Azure、实时语音或其他模型；没有输入真实儿童资料，也没有获得真实专业批准。**源目录仍有 32 个未审核开发包、0 个真实批准、6 个包配置中文声音。**

技术实现与范围见 [素材库设计](../MEDIA-LIBRARY.md)，完整目标见 [实施账本](../IMPLEMENTATION.md)。源文件、构建、日志和截图摘要保存在 [本轮证据清单](media-library-runtime-v0.15.json)。

### 媒体专项断言

1. PNG 完整解码及元数据去除；JPEG 冒充、奇数/过小尺寸、动画控制块和尾随载荷拒绝。
2. 实际 MP3 解码、时长/电平、压缩帧复制和再次解码；无效输入和工具不可用拒绝。
3. 同幂等键重试返回原意图，改变内容冲突；错角色和改变字节拒绝；原件/交付对象去重，导入记录与请求私有字段隔离。
4. 无效格式使导入终止为 rejected；工具不可用保持 awaiting；24 小时到期不能再上传。
5. 新图片换稿、冻结后拒绝修改、两种角色分别完成合成事件试玩后批准、签名发布、重新加载与召回；旧源包不改变。
6. 年龄、已有图像槽位、声音语言和逐字字幕约束；正确录音可绑定对应 copyKey。
7. 合成静音、0.03 秒短音及 121 秒长音拒绝。合成音仅用作测试夹具，不是儿童配音。

HTTP 测试使用新的彩色 PNG 夹具与项目录音的轻微音量变体，确保交付字节不等于已公开内置文件；真实请求检查缺少 CSRF 的 PUT 拒绝、发布前 404、签名发布后摘要一致、重启仍有 2 条 ready 导入、召回后 404。该变体在测试准备阶段编码；导入处理本身仍复制 MP3 帧，不二次有损编码。

初期曾用与内置文件相同的 MP3 测试“发布前 404”，实际返回了原本公开的字节。随后明确访问模型并修正夹具，而没有声称同字节再导入可以撤销既有公开访问。引用的日志均为最终通过版本。

## 保留的限制

- 没有 OS 沙箱、杀毒扫描、资源总量隔离或云对象生命周期；有限格式解析与超时不构成完整生产上传防护。
- 源文件和处理后文件存本地数据库，容量/条数有限；尚无分页、归档/删除界面和保留期限任务。原件不开放下载接口。
- 技术检查不证明字幕真伪、版权、录音授权、适龄性或自然度；导入声明不等于专业批准。
- 当前只有 LOCAL 预览、开发身份和本地签名密钥；已有公开/缓存字节不能通过召回物理收回。
- 原生安装包、全设备计时/加密/无障碍、真实专业审核、全球身份/地区准入、青少年共享、支付客服及效果研究仍待完整建设与验证。
