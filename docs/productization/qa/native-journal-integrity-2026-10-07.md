# 原生恢复日志完整性：本地工程验收

2026-10-07。Android 与 iOS 的 SQLCipher `journal` 新增逐记录 `events_hash`。保存事件、摘要和离线恢复检查点时沿用同一个事务；读取练习日志或家长导出时，重新计算规范化事件摘要并与已保存值核对。摘要不一致或事件无法解析时拒绝使用该条日志。家长导出沿用已实现的部分交付提示：服务端记录可继续取得，`localRecovery.status=unavailable`，不把本机缺失伪装为空记录。

旧版数据库在打开时只新增可空字段，不改写既有事件。旧行导出标为 `legacy-unverified`；新写入或更新后的行带摘要，导出标为 `verified`。导出同时包含本机日志保存时间，其他设备的日志仍需分别导出。撤回与删除的封闭标记、七天保留期和 SQLCipher 密钥边界没有改变。

专项 SQLite 与摘要检查覆盖：内容变化被拒绝、旧行保留、新写入与更新的事件和摘要同步、损坏日志转为导出 `unavailable`，以及原有的撤回、过期和离线准备约束。完整业务测试 **414/414**、两端类型检查和 iOS/Android Hermes 运行代码导出通过。此处是源码与本地 SQL 测试；尚未在安装包上完成旧库升级、磁盘损坏、低存储、后台中断和实际系统分享验证，不能视为 D03 设备门槛通过。
