# v0.42 青少年策略足迹：实现与验收

2026-10-01。本批为使用虚构资料的本地开发预览，不代表真实家庭试用或商业开放。

## 本批范围

- 12–14、15–17 岁孩子空间在 Web 和原生 App 增加双语「我的策略足迹」。页面只读展示本人已结束练习的任务、日期、完成／提前结束／换设备前状态，以及该任务当前可选的下次练习策略。策略属于现行内容建议，不声称是对当次表现的个性化诊断。
- 新接口仅接受当前孩子作用域，逐次核对家庭、孩子和会话有效性；家长作用域、其他孩子、6–11 岁及撤销会话不能读取。每页至多 20 条，按服务端时间和记录标识稳定翻页；返回不含总分、逐次输入、反应时、生活回顾答案或其他孩子数据。
- 客户端验证响应与当前档案匹配。权限失效或响应异常时清除旧页；短暂网络错误保留已读页供重试；离开页面后迟到响应不会重新显示。家长可见练习记录、生活回顾由孩子主动分享的边界在页面中说明，尚未实现独立青少年登录身份。

## 验收证据

- 完整业务测试 **302/302**、本地 HTTP 测试 **15/15**；定向检查覆盖微秒级翻页、跨孩子游标、较小年龄、撤销、故障重试、异常扩大字段及离页迟到响应。
- Web 发布构建、原生类型检查及 Android/iOS 运行代码导出通过。Web 首屏静态文件总量 **1,499,746 字节**，在 1,500,000 字节构建门槛内；余量很小，下一次改动需优化资源。
- 隔离本地服务的虚构 15–17 岁档案完成一次提前结束练习，浏览器实际核对了「我的策略足迹」中文和英文页面、任务、状态、策略建议和无总分展示。未对真实儿童或设备进行可用性研究。
