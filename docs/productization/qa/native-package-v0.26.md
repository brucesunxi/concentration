## 空间与构建复现

构建前可用空间约 1.6 GiB。确认没有 Xcode 构建运行、旧目录没有打开的文件后，仅移除旧 Debug 构建的 `Intermediates.noindex` 缓存；当前构建、源码和已交付安装包保留。记录见 [缓存处理](native-package-v0.26/cache-cleanup.json)。完成交付时约有 2.9 GiB 可用。

团队使用 [原生构建交接](../NATIVE-APP.md) 的新隔离目录准备与构建命令即可复现。若复用已有目录，先核对原源码快照、依赖锁、原生配置和当前运行进程，再更新允许清单中的源码；依赖或原生配置变化时重新执行对应原生准备步骤。不能把旧目录名当成产物版本，也不能仅替换 ZIP 文件名。

## 下一步设备验收

1. 启动本机家庭 API；使用虚构家庭。iPhone 17 模拟器已安装本批 App，解锁 Mac 后从冷启动开始验收。
2. Android 连接 arm64 设备，运行 `adb reverse tcp:4181 tcp:4181`，再安装本批 APK；API 保持本机监听。
3. 为同一虚构孩子准备超过 50 条练习与观察记录。分别前进、返回、重新读取最新记录，并切换中文儿童与英文青少年档案；检查另一个集合和孩子的数据没有混用。
4. 验证断网/超时保留页码、恢复后重试、后台锁定，以及撤销登录后私人记录清除。
5. 继续执行原有音频、任务触摸与时序、系统导出、SQLCipher 文件、离线冷启动和升级矩阵。

**设备界面仍未验收**：本次 UI 工具检查时 Mac 锁屏，Android 未连接设备。没有启动或观察 App 界面；安装和摘要一致不能代替这些结果。真实设备、专业内容审查、家庭研究及商业发布要求继续保留。
