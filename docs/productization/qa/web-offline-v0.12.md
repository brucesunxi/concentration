# Web 断网重开验收记录

2026-09-30 · 平台 0.12.0 · 引擎 2.0.0 · 内容 0.7.2-preview · 原生应用版本仍为 0.2.0。

## 验收结论

构建后的 Web 已能保存一份经过核验的练习，在家庭服务不可达时关闭页面后重开，恢复已有记录，继续或离线结束，重新连接后完成补传与确认。第二个页面不能同时写练习，身份变化会收起其他页面的家长视图。该结论限定于本次内置浏览器、虚构家庭和下述场景。

### 新增自动检查

`tests/platform/web-offline.test.ts` 使用 `fake-indexeddb` 和真实共享内容/授权核验代码：

1. 新连接读取同份资料，Web 核验通过，错误原生平台拒绝；不包含昵称。
2. 旧 v1 日志原位保留，错误所有者拒绝，合法写入补齐家庭字段。
3. 另一个连接改变身份代次后，旧保存/准备失败，原日志保留。
4. 撤回档案后，晚到保存与新连接都不能复活记录。
5. 非最终关闭保留结束/历史上传能力；最终关闭即使再调用非最终关闭，仍拒绝晚到写入。
6. 不匹配的事件快照不能准备恢复；最高时间不倒退，已知时钟故障不丢失。
7. 模拟配额错误时，事件、摘要和检查点一并回滚。

`tests/offline-worker.test.mjs` 在模拟 worker 作用域中执行实际生成的代码：离线公共文件读取；API/写请求/查询参数/跨来源绕过缓存；坏版本安装保留旧缓存；仅清理本产品旧网页版本；清单完整性和当前入口匹配；驱逐后离线失败、在线校验修复；拒绝私有、外部、路径穿越和不允许类型的清单路径。

模拟检查不能替代真实浏览器配额错误、系统缓存驱逐或原生加密文件验收。

### 本次实际操作发现并修复的问题

- 同一页面的两个 BroadcastChannel 实例也会互相收到消息。自己的“开始练习”通知曾让页面把新状态当作过期结果丢弃；增加消息来源过滤后，“开始 → 规则页”及跨页权限刷新均复验通过。
- 第二页取得练习锁失败时，原提示还会说“已恢复”。现在只有恢复初始化完成且未锁定时显示成功说明。
- 无可恢复记录时曾回到建家庭表单。现在单独显示重连入口，保留记录说明。
- 重连页曾回到默认中文。现在保存仅含语言代码的偏好；没有偏好则根据浏览器语言选择，英语离线重开已复验。
