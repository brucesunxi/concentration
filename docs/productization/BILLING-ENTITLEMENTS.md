# 成人购买与家庭权益：已实现的计算核心和接入边界

2026-10-01。`packages/billing/entitlement.ts` 已实现纯函数权益账本，用于未来服务端在**核验渠道事实之后**计算家庭访问状态。当前预览没有收费入口，也没有把此模块接入新练习准入；家长和孩子的现有预览流程不受影响。

## 当前确定的行为

- 同一来源的渠道事件以 `eventId` 去重；同一标识却有不同内容时拒绝，恢复购买不会重复增加权益。
- 购买期以交易标识归档。退款即使先于购买通知到达，也会阻止该交易恢复权益；另一笔有效续费仍可独立授权。
- 取消自动续费只更改续费状态，不提前切断已付款周期。权益在区间结束时自然到期。
- 渠道适配器提供单调版本的续费与宽限状态；迟到的旧状态不能覆盖新状态。宽限只在该产品曾有未退款的有效购买期时适用。
- 多渠道权益分开记录，再选择当前有效期最晚的一份；状态区分 `free`、`active`、`grace`、`expired` 和 `refunded`。计算只依赖明确传入的时间，便于重放。

## 接入前仍须完成

1. 建立独立的家庭权益和不可变渠道事件表，按家庭绑定购买原始标识，并在数据库层全局唯一约束渠道事件与交易归属。先在隔离 Neon 分支迁移和做并发/备份验证，再更新受保护预览库；当前 Vercel 运行账号不能自行建表。
2. 按获准销售地区分别接入 App Store、Google Play 和 Web 渠道。客户端回执与 Webhook 本身都不直接授予权益；服务端验证签名、向渠道查询最新交易，再转换为本模块接受的事实。`verifiedBillingFactSchema` 只检验结构，**不**核验渠道签名或商户身份。
3. 将权益读取与新会话创建放在同一家庭事务中，并为已签发的离线练习保留明确边界。退款、通知延迟与服务暂时不可用时，不能向孩子显示付费催促，也不能删除记录或挡住导出、注销。
4. 在家长空间完成价格、周期、试用、续费、取消、退款、恢复购买和客服联系流程；文案及渠道外链逐市场审查。真实收费、门槛启用与效果表述分别经过发布审批。

当前测试覆盖通知重复、乱序退款、恢复购买、取消续费、宽限到期和多来源选择。它不是商店沙盒或真实交易验收；B-01 仍为进行中。
