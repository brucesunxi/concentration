# 成人购买与家庭权益：已实现的计算核心和接入边界

2026-10-02。`packages/billing/entitlement.ts` 已实现纯函数权益账本，用于未来服务端在**核验渠道事实之后**计算家庭访问状态。schema 32 增加了家庭权益账本及渠道事件去重表，新练习入口通过只读适配器在家庭事务内读取权益。当前预览没有收费入口，也没有真实渠道适配器；家长和孩子的现有预览流程不受影响。

## 当前确定的行为

- 同一来源的渠道事件以 `eventId` 去重；同一标识却有不同内容时拒绝，恢复购买不会重复增加权益。
- 购买期以交易标识归档。退款即使先于购买通知到达，也会阻止该交易恢复权益；另一笔有效续费仍可独立授权。
- 取消自动续费只更改续费状态，不提前切断已付款周期。权益在区间结束时自然到期。
- 渠道适配器提供单调版本的续费与宽限状态；迟到的旧状态不能覆盖新状态。宽限只在该产品曾有未退款的有效购买期时适用。
- 多渠道权益分开记录，再选择当前有效期最晚的一份；状态区分 `free`、`active`、`grace`、`expired` 和 `refunded`。计算只依赖明确传入的时间，便于重放。
- 每条正式发布规则必须明确选择 `open-pilot` 或 `family-entitlement`，并将此选择纳入发布身份。前者允许获准免费试用；后者只在创建新练习时接受同一家庭事务内读取的 `active` 或 `grace` 权益。无读取器或读取失败返回 `ENTITLEMENT_UNAVAILABLE`，其他状态返回 `ENTITLEMENT_REQUIRED`。同一请求的合法重试和已有会话续练不重新核验权益。
- 渠道来源标识只能归属一个家庭，渠道事件标识在同一供应商下全局唯一；重放相同事件不重复更新，标识相同但内容不同会冲突并回滚。家庭运行账号只能读取本家庭权益，不能写账本或读取原始渠道事件；删除家庭会级联清理记录。当前只有供未来已核验渠道适配器调用的服务端写入函数，没有家长或孩子可调用的支付成功接口。
- 创建者家长可以在 Web 和原生家长空间只读查看家庭使用状态。接口只返回预览/免费/有效/宽限/到期/退款状态、有效期和续费开关，不返回购买交易号或渠道事件。当前受保护预览明确说明不收费；协作家长和孩子不能打开该入口，权益读取失败不会挡住家庭登录或已有记录。

## 接入前仍须完成

1. 完成渠道事件真实性和交易归属验证后才能调用账本写入函数；当前结构校验并不验证 App Store、Google Play 或 Web 的商户身份。并发通知、Neon 恢复及备份清除仍须用渠道沙盒和独立环境验收。
2. 按获准销售地区分别接入 App Store、Google Play 和 Web 渠道。客户端回执与 Webhook 本身都不直接授予权益；服务端验证签名、向渠道查询最新交易，再转换为本模块接受的事实。`verifiedBillingFactSchema` 只检验结构，**不**核验渠道签名或商户身份。
3. 在正式启用收费规则前，还须实现经过审核的试用额度、购买恢复及跨设备归属处理，验证并发通知和故障恢复。退款、通知延迟与服务暂时不可用时，不能向孩子显示付费催促，也不能删除记录或挡住导出、注销。
4. 在家长空间完成价格、周期、试用、续费、取消、退款、恢复购买和客服联系流程；当前只读状态页不代表这些购买能力已开放。文案及渠道外链逐市场审查。真实收费、门槛启用与效果表述分别经过发布审批。

当前测试覆盖通知重复、乱序退款、恢复购买、取消续费、宽限到期、多来源选择，以及持久化写入、家庭隔离、受限运行账号和新练习准入。临时 Neon 数据库通过 schema 32 重复迁移与角色检查；这不是商店沙盒或真实交易验收。B-01 仍为进行中。
