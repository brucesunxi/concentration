# 家庭空间注销：当前实现与边界

家庭创建者可在 Web 和原生 App 的“账号与登录”中注销整个家庭空间。操作要求最近十分钟内重新验证过的创建者会话、当前密码、完整家庭名称和明确确认；协作家长与孩子模式没有入口，服务端仍独立拒绝。浏览器请求使用同源及 CSRF 校验，原生凭据只通过原生通道使用。

服务端在同一数据库事务内验证身份和密码，然后删除家庭主记录。家庭成员、孩子档案、练习、事件、观察、生活目标、邀请、监护许可和会话通过外键级联删除。密码错误会计入现有的账号锁定计数。删除完成后，旧 Web、原生及孩子凭据均失效；重复提交不能恢复资料。其他家庭不受影响。

Web 在收到确定的成功响应后清除此家庭在浏览器中的恢复日志并通知其他标签页，同一浏览器内其他家庭的日志和恢复状态保留；原生客户端清除本机离线日志和安全存储凭据。若请求结果不明，界面不会宣称删除成功，并引导家长重新登录核对。若服务器已确认删除而浏览器清理失败，界面单独提示清除本站浏览器存储。

**边界：**其他离线设备可能在原授权期限内显示旧内容，联网后不能再上传到已删除家庭。已导出的外部副本不能由产品远程清除。数据库备份的保留、清理时限与客服核查流程须在真实家庭试用前由运营和法务明确；当前实现只证明活动数据库中的记录删除。上线前还需要在隔离的 Neon 分支、目标原生设备、不同浏览器及故障注入下验证完整流程。
