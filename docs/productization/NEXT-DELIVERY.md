# 全球家庭产品的下一阶段实施交接

2026-10-01。面向产品、研发、设计、内容、研究和测试负责人。本清单把现有 v0.46 本地版本接入完整产品路线；目标是推进到可招募真实家庭的受控试用版本。商业开放仍须完成 [执行计划](DELIVERY-PLAN.md) 的发布门槛。

## 1. 已确认的产品方向

用户面向全球儿童与青少年以及家长，采用家庭直接使用与购买的模式。已有完整研发团队，以下任务分配到现有人员；科学、研究、母语审核与地区法务另需落实专业责任人。

首期年龄范围建议为 6–17 岁，分 6–8、9–11、12–14、15–17 四档。6 岁以下另行研究；18 岁时需重新确认账户与共享权限。英语和简体中文先建立完整内容闭环，每个国家、年龄、语言、平台的组合单独开放。全球适配从架构阶段开始，发布范围随证据逐步增加。

产品闭环为：**孩子理解规则 → 短时练习一个策略 → 在生活中尝试 → 家长提供支持 → 一起回顾具体变化**。不设置机构班级、教师排名或学校销售依赖。家庭订阅、续费、取消和退款由家长端承接；儿童和青少年端保持可退出、可休息和可自主选择。

固定语音沿用已认可的中文音色制作流程，逐语言进行母语审核和音频质检。运行时播放已审定素材；语音生成供应商凭据只进入制作环境，不能出现在 App 包、前端或产品文档中。

## 4. 随后两周的纵向交付

优先把一个已批准发布组合做完整：家长注册及必要监护同意 → 孩子档案 → 一份已审核任务 → 暂停/休息/离线结束 → 服务器确认 → 家长回顾 → 撤回与删除。候选国家或供应商未定时，允许使用明确标记的开发适配器；该适配器不能满足正式试用门槛。

同时交付家长购买链路的沙盒方案：权益归属、商店回执核验、重复通知、恢复购买、取消、到期、退款和跨设备权益。孩子端不放促销催促。真实收费须在主体、渠道、条款、客服和相应发布条件通过后启用。

内容团队使用现有两个独立队列：任务与固定语音，以及按年龄组合的双语家长课/生活模板。家长内容流程已实现，见 [审核发布操作](FAMILY-CONTENT.md)；专业内容与完整媒体仍待审定。测试团队优先覆盖不同年龄、语言和平台的交叉失败，不只验证理想路径。完整年龄与语言矩阵在 [执行计划](DELIVERY-PLAN.md) G2 前分别验收。

## 5. 研究与商业判断

先验证孩子是否理解、是否愿意继续、家长能否提供合适支持，以及记录是否可靠；随后检验日常功能结果。任务表现、生活观察和研究量表分别呈现。家庭观察只能说明可用性，不能证明训练有效。

计算机认知训练的研究结果受任务、人群和评价方式影响，已有综合研究不能直接证明本产品改善所有儿童的日常专注力。正式效果研究需要预先确定主要结果、主动对照、样本量、随访、缺失数据处理与版本冻结，详见 [2023 年研究综合](https://pubmed.ncbi.nlm.nih.gov/36977764/) 与 [2026 年研究综合](https://pubmed.ncbi.nlm.nih.gov/42110889/)。

32 周是原路线中满足条件后的有限市场发布目标，不能按现有功能数量折算完成比例。已有工程可减少部分实现工作，家庭观察、内容审核和研究仍需要实际周期。研发容量由现有团队映射到 [执行计划](DELIVERY-PLAN.md) 的约 12 个全职等效职能；新增外部支出和人员占用成本分别估算。

## 6. 真实家庭试用的通过条件

试用前须由对应负责人逐项签署：

1. 明确的年龄、语言、市场、平台和用途，关闭未批准组合。
2. 实际家长身份与必要监护同意、孩子参与意愿、随时退出及资料处理流程可运行。
3. 一套完整任务和相关声音、图像、家长内容已审定。
4. 目标设备关键流程通过，离线数据缺失和异常能被发现与解释。
5. 支持联系人、不适处理、版本召回、故障响应和研究安排可执行。

美国适用要求以 [FTC 的现行规则指引](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions) 为入口核查，该页要求参照修订规则；商店发布按最终形态核对 [Apple 审核指南](https://developer.apple.com/app-store/review/guidelines/) 等渠道要求。上述清单是工程与产品交接，不代表已完成各国法律审查。完整来源和市场差异见 [证据与来源](EVIDENCE.md)。
