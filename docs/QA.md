## 课程与语音素材

- `npm test` 额外覆盖 4 周循环的日程生成、当天技能轮换、分技能进度快照和 v1 到 v2 数据迁移。
- `src/audio/manifest.js` 覆盖所有固定的儿童提示，且运行时不会请求 `/api/voice`。
- 配置 `OPENAI_API_KEY` 后执行 `npm run voice:generate`，逐个检查 MP3 能播放、音量统一、中文发音和停顿自然；没有素材时应显示设备语音回退。
- 本地服务首页返回 HTTP 200。

交互验收使用 localhost:4173，包含合成测试记录；用户交付使用同服务的 127.0.0.1:4173，该浏览器存储空间独立、初始无记录。
